# 观潮形态克隆 · 难度评估与开源轮子地图

> **报告日期：** 2026.05.19  
> **目的：** 评估"从零造一个观潮"的工程量与可行性  
> **核心结论：** 8 个模块里 7 个有现成开源轮子，Pine Script 是唯一硬骨头

观潮源码拿不到、也不该拿。但功能形态可以用开源组件组装出来。这份文档拆解 8 个核心模块，给每个模块标注：可用的开源轮子、难度系数、能复刻到几成、绕不开的硬骨头。

---

## 三条不可越过的红线

1. **不要扒前端代码。** 哪怕能用 DevTools 看到 JS，把它转译成自己的代码也是侵权——它的 K 线引擎、缠论算法、定价页的具体实现都受版权保护。

2. **不要反编译桌面客户端。** 服务条款明确禁止"反向工程"，违反就是直接踩在著作权法 + 反不正当竞争法上。

3. **不要照搬商标、品牌名、LOGO、视觉语言。** 自己起一个名字，自己设计 UI——可以参考布局逻辑，但不能像素级抄袭。

**能做什么：** 研究它有什么功能、解决什么问题，然后**用开源组件 + 自己的代码 + 自己的设计**做一个功能类似的产品。这条路完全合法，业界（TradingView 克隆产品、各种通达信替代品）都是这么干的。

## 总体难度评估

"完全复刻观潮形态"是个怎样规模的工程——三档对照。

| 目标 | 工期 | 人力 | 覆盖度 |
|---|---|---|---|
| **最低 MVP**（能给人看的 demo） | 3-4 个月 | 1 人 + Claude Code | 核心 50% |
| **功能对标**（用户能用） | 12-18 个月 | 2-3 人 + AI | 核心 80% |
| **商业化级**（能稳定收钱） | 18-24 个月 | 3-5 人 | 商业可付费 |
| **综合难度** | ★★★★ / ★★★★★ | 8 个模块，1 个是真的硬 | — |

**关键判断：** 用 Claude Code 这种 AI 协作模式，一个人在 3-4 个月做出"看起来像观潮的 MVP"是**完全可行的**——前提是接受 30% 功能砍掉、Pine Script 用替代方案、不做桌面客户端。

## 8 个核心模块的工程量

### 01 · K 线图表引擎

> Canvas/WebGL · 60 FPS · 万根 K 线 · 60+ 画线 · 70+ 指标

- **难度：** ★★
- **能复刻：** 95%
- **工期：** 2-4 周

**可用开源：**

| 项目 | 描述 | License |
|---|---|---|
| klinecharts/KLineChart | 国产首选，零依赖，移动端友好，70+ 内置指标，画线工具齐全 | Apache 2.0 |
| tradingview/lightweight-charts | TradingView 官方开源，35KB，性能最强，但画线工具弱 | Apache 2.0 |
| **KLineChart Pro** | KLineChart 团队的"开箱即用"版本，已带完整 UI，**最接近观潮形态** | Apache 2.0 |

**评估：** ✓ EASY — 观潮宣传的"WebGL + Canvas 混合渲染"，KLineChart Pro 直接给你 90% 的能力。剩下 10% 是自己加几条特殊画线和品牌化定制。

### 03 · 数据层（A 股 / 美股 / 全球）

> 3949+ A 股 · 30 年历史 · 分钟级 · 龙虎榜 · 北向资金

- **难度：** ★★
- **能复刻：** 95%
- **工期：** 2-3 周

**可用开源：**

| 项目 | 描述 | License |
|---|---|---|
| akfamily/akshare | 国内最强免费数据源，覆盖 A 股/港股/美股/期货/外汇/加密，含 AKTools HTTP API | MIT |
| waditu/tushare | A 股数据规范，积分制（基础免费），适合作为 AKShare 的备份 | BSD |
| ranaroussi/yfinance | 美股 + 全球，非官方但稳定，适合美股扩展 | Apache 2.0 |

**评估：** ✓ EASY — 观潮十有八九就是 AKShare + 本地数据库的组合。复刻它的数据层 = 部署一个 worker 每天增量拉数据存到 ClickHouse/PostgreSQL。最大的工作量在**"数据清洗 + 复权处理 + 多源对账"**，而不是接入。

### 04 · AI 多视角研判

> 技术/基本/消息/价值四 Agent · 交叉质证 · 形态识别 · 情绪分析 · 综合置信度

- **难度：** ★★★
- **能复刻：** 85%
- **工期：** 3-5 周

**技术栈：**

| 项目 | 描述 | 成本 |
|---|---|---|
| DashScope / 通义千问 API | 观潮宣传"Qwen3.6-Plus"，直接调阿里云。中文金融语料强，性价比最高 | ¥¥ 按 token |
| DeepSeek-V3 / Claude / GPT-4 | 备选 LLM，应该多 provider 走 LiteLLM 之类的统一层 | ¥¥ 按 token |
| LangChain / LangGraph | 多 Agent 协作框架，编排"技术/基本/消息/价值"四个 Agent | MIT |

**评估：** ~ MEDIUM — **技术不难，难在 prompt 工程。** 四个 Agent 各自的 prompt 模板要打磨几十轮才能稳定输出结构化 JSON。AI 答案的"专业感"完全取决于 prompt 写得好不好——这是真正花时间的地方。

### 05 · Pine Script 策略引擎 ⚠️

> 语法兼容 · 沙箱执行 · 断点调试 · 参数优化

- **难度：** ★★★★★（最高）
- **能复刻：** 30%
- **工期：** 3-6 个月

**现状：**

Pine Script 是 TradingView 的**专有语言**，没有完整的开源解释器。社区有几个尝试（pinescript-translator 之类），但都只能跑最基础的语法，复杂策略全部失败。

**替代方案（务实选择）：**

| 项目 | 描述 | License |
|---|---|---|
| vnpy / vnpy-evo | 国内最成熟的量化框架，自带策略 DSL + 回测 + 实盘，绕过 Pine Script | MIT |
| backtrader | Python 量化老牌框架，策略写法简单，回测能力完整 | GPL-3.0 |
| microsoft/qlib | 微软出品，含 A 股数据 + 量化平台，适合做"机构感"的回测 | MIT |
| **自研 DSL（推荐）** | 设计自己的策略语言（比如 YAML 配置 + Python 表达式），AI 自然语言生成，绕开 Pine Script 兼容 | 自有 |

**评估：** ✕ HARD — **这是真正的硬骨头，也是观潮真正的护城河。** "Pine Script 兼容"意味着要写一个完整的 lexer + parser + 运行时 + 沙箱，还要兼容 TV 的几百个内置函数。即使做出来 70% 兼容，那 30% 就是用户用着用着卡住的点。

建议直接放弃 Pine Script 兼容，用 **"自然语言 → 自研 DSL → 回测"** 这条路绕过去。早期用户根本不知道 Pine Script。

### 06 · 回测引擎

> Walk-Forward / Monte Carlo / 参数优化 · 权益曲线 · 回撤 · 夏普 · 跨股扫描

- **难度：** ★★★
- **能复刻：** 90%
- **工期：** 3-4 周

**可用开源：**

| 项目 | 描述 | License |
|---|---|---|
| backtrader / vnpy / qlib | 三选一，都能撑起完整回测能力 | MIT |
| QuantConnect/Lean | .NET 写的开源回测框架，**跟 CryptoSharp 同一技术栈！** | Apache 2.0 |
| vectorbt | 基于 NumPy 的高性能回测，参数优化能力极强 | Pro 部分付费 |

**评估：** ✓ EASY — CryptoSharp 已经有自己的回测引擎了。把权益曲线/回撤这些核心指标做完，再加 Walk-Forward + Monte Carlo 就达到观潮宣传水准。**对你来说这模块的工程量基本为零**——已经有了。

- **难度：** ★★★
- **能复刻：** 95%

## 落地路径 · 5 步走

如果真要做，每一步明确目标 + 工期 + 完成判定。

### Step 01 · 第 1-3 周 · 骨架搭建：能跑起来一个图

**目标：** Next.js + KLineChart + AKShare（HTTP API 通过 AKTools）+ PostgreSQL + Redis，能在网页上画出一只股票的 K 线和 5 个常用指标。

**判定：** 用 600519（贵州茅台）打开页面，看到完整的日 K 线、MA/MACD/RSI 三个指标、缩放拖动流畅。

`tech: Next.js · KLineChart · AKShare · PostgreSQL · Redis · Docker`

### Step 02 · 第 4-7 周 · 核心差异化：缠论 + AI 决策卡

**目标：** 集成 czsc 库画出缠论的笔/段/中枢/买卖点；接入通义千问做"四 Agent 研判"输出结构化卡片。

**判定：** 同一只票自动标出缠论结构 + 给出"技术/基本/消息/价值"四视角评分 + 综合置信度。

`tech: czsc · DashScope · LangGraph · 自研 DSL（替代 Pine Script）`

### Step 03 · 第 8-11 周 · 商业化骨架：用户体系 + 定价 + 付费

**目标：** 注册登录、四档定价、Stripe（海外）或微信/支付宝（国内）支付、订阅管理、72h 退款、电子发票。

**判定：** 一个真实用户能完成"注册 → 试用免费版 → 升级 PRO → 收到发票 → 在 cooling-off 内退款"全流程。

`tech: NextAuth · Stripe · 微信支付 · 自动续费 · 工单系统`

### Step 04 · 第 12-15 周 · 产品打磨：UI 视觉 + 引导 + 营销页

**目标：** 深色专业感视觉系统打磨、首页/功能页/定价页/关于页四个营销页、新用户引导动画、文档站。

**判定：** 把官网给陌生人看，能在 30 秒内说出"这是干嘛的、值不值这个价"。

`tech: Tailwind · Framer Motion · Mintlify（文档）· Plausible（分析）`

### Step 05 · 第 16-20 周 · 合规外壳 + 上线运营

**目标：** ICP 备案（个人/个体工商户）、服务条款 + 隐私政策、免责声明全站植入、18+ 强制声明、首批 100 用户内测。

**判定：** 能光明正大挂在国内外社交媒体上推广，不被举报、不被下架。

`tech: 个体工商户注册 · 阿里云/腾讯云 ICP 备案 · 律师审核条款`

## 该不该做？

### ✓ 三个 YES

**技术可行：** 8 个模块里 7 个有现成开源轮子，Pine Script 这一个硬骨头可以用自研 DSL 绕过。

**市场可行：** 观潮证明了"散户用 ¥39/月愿意付"，这条赛道有可见的天花板。

**资源可行：** 1 人 + Claude Code，3-4 个月做出 MVP，6 个月达到可商业化水平。

### ✕ 三个 NO

**不要照抄品牌：** 名字、Logo、视觉、文案不能像素级复制，得自己起一个。

**不要逆向源码：** 反编译它的桌面端、扒前端 JS 都是违法的，零容忍。

**不要硬刚 Pine Script：** 这是观潮真正的护城河，硬磕 6 个月也未必能做出 80% 兼容。用自研 DSL + AI 自然语言生成绕过去，反而是更现代的体验。

## 最务实的开始

用一周时间，先把 `yijixiuxin/chanlun-pro` 这个开源项目跑起来——它本质上就是**"一个免费的小观潮"**。把它的 UI 改成你想要的样子、数据源切到 AKShare、加上 AI 决策卡，**三周内就能有一个能给用户看的 demo**。然后再决定要不要全力做。

不要一上来就憧憬"做一个观潮"——先证明给自己看"这条路真能走通"，再投入 6 个月时间。
