## 2. ★ 现实评估(诚实,不画饼)

**撑「涨跌家数 + 榜单」需要什么**:全市场(或足够多)港股的**最新价 + 涨跌幅**。
- 涨跌家数 = 统计 N 只里涨/跌/平 → N 越大越有意义(全市场 2764 才是真「涨跌家数」)。
- 榜单 = N 只按涨跌幅/成交额排序 → N 越大榜越真实。

**新浪 `stock_hk_spot` 能一次拿全(2764 只)**:
- ✅ 单接口拉全市场(不是逐个),一次请求 ~2764 行 → 直接算全市场涨跌家数 + 全市场榜单(**A股级丰富度**)。
- ⚠️ 封 IP 风险:新浪对高频抓取封 IP(`stock_zh_a_spot` 源码注释明说)。→ **低频采**(每 3-5 分钟一次全市场快照,同 A股 cn_board_scan 每 3 分钟,已验新浪能接受)。
- 耗时:单接口全市场 ~数秒(本地实测含东财卡顿共 ~1 分钟,纯新浪应更快)。
- 数据延迟:新浪 spot 通常实时~轻延迟(交易时段),非交易时段为最新收盘。

**对现有架构影响**:
- spot 快照(非 K 线)→ 新建 `hk_spot_snapshot` 表(照 `cn_spot_snapshot`/`us_spot_snapshot`),**不动 kline 表**。
- 单接口全市场 = 轻量(比 us 逐个 128 只还省请求)。worker 加一个 `hk_board_scan` task(照 cn/us)。
- 历史 K 线维持现状(yfinance 逐个,详情页 cache-aside 已工作),**全市场历史不采**(首页只要 spot)。
