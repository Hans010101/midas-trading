## TL;DR

- **①信号价格 + ②历史信号列表 = ✅ 后端现成**(`StrategySignalsResponse.signals` 已输出全历史 ts/price/kind/reason)→ **轻 · 纯前端展示**。

  - **形态A 策略信号(均线/RSI/布林)命中率完全没接**(`strategy_signals` 不进 memory/reflection);
  - → **不能现在做真命中率**,要么展示位「样本积累中」,要么新建策略信号闭环(大工程 + 等数周样本)。

## 1. ★★ 第③项 命中率(最关键 · 先查清,别混)

**生产 `/api/v1/analysis/ai-accuracy` 现状(2026-06-01 实测)**:
```
overall_hit_rate: null · overall_sample_count: 0
by_market: cn/us/crypto 全 sample_count=0 · reliable=false
by_direction: bull/bear/flat 全 0
```
→ **全空,0 样本**。当时定 reliable≥20 才可靠,现在远不够(0)。

**★ 关键区分(产品负责人强调别混)**:
| | 记的是什么 | 闭环现状 | 数据 |
|---|---|---|---|
| 批次乙 memory→reflection→accuracy | **AI 决策卡(decision-card)** LLM 判断 | ✅ 闭环全在(beat 每日 04:30 reflect)| ❌ **生产 0 样本** |
| **形态A 策略信号**(金叉/RSI/布林)| —— | ❌ **完全没接**(strategy_signals 不记 memory)| ❌ 无 |

- **决策卡命中率**:闭环现成(`record_decision` 在 decision-card cache-miss 后记 + reflection 回填 + accuracy 三维分桶 + ai-accuracy 端点),但**生产 0 样本** —— 可能用户调决策卡少 / 闭环刚上线没攒够(reflection 需 7 天前的决策才回填)。**数据待攒,现在做不了真命中率。**
- **策略信号命中率**:`strategy_signals` 输出信号点后**没有任何记录/回填**。要做策略信号命中率 = **新建一整套闭环**(每个策略信号 → 记库 → N 天后回填实际涨跌 → 判对错 → 算命中率),类似批次乙但针对策略信号 → **大工程 + 同样要等数周样本**。

**第③项诚实结论**:现在两条路都没数据。建议:① **展示位先挂「样本积累中 · N 条已记录」**(诚实,决策卡闭环在)· 或 ② 策略信号命中率单独大单元新接(重 + 等样本)· **不建议堆进单元4**。

## 2. 第①信号价格 + ②历史信号列表 = ✅ 后端现成,轻

`StrategySignalsResponse`(单元1/2 已做)已输出:
- `signals: list[StrategySignal]` —— 全部历史信号点,每个含 **`ts`(信号 K 线时间)+ `price`(该根收盘价)+ `kind`(buy/sell)+ `reason`(金叉/超卖反弹/触轨)**。
- `current_triggered`(当前是否触发)+ `last_signal`(最近信号)。

→ **①信号价格已有**(`StrategySignal.price`)· **②历史信号列表后端已输出**(signals 全历史)。**后端零改**,前端只需在策略面板加一个历史信号列表 UI(逐行展示 ts/价格/方向/依据)。**轻。**

## 3. 第⑤项 关键价位(布林上下轨/均线值)= ⚠️ 算了没输出,中

- 均线值:`indicators.compute_ma` 算了(dict[period→value]),但没进 strategy API。
- 布林上下轨:`strategy_signals.scan_boll_reversion` 内用 `_sma`±k`_stdev` 算了轨,但只产信号点,**没输出轨值**。
- → 要补:strategy API 加「当前关键价位」字段(布林上/中/下轨 + 关键均线值)。后端**数据现成(已算),加 schema 字段透出**即可。**中(偏轻)。** 备选:前端 klinecharts 已画 BOLL/MA,可前端取值标注(更轻但耦合图表)。

## 4. 第⑥项 信号成色(金叉角度/RSI 数值)= ⚠️ 部分算了没输出,中

- RSI 数值:`strategy_signals._rsi_series` 算了,但没透出。
- 趋势/布林位置 pctb:`strategy_recommend._pick(trend, rsi, pctb)` 算了,但 `StrategyRecommendation` **只输出 `reason` 文字**(无数值字段)。
- 金叉角度:**没算**(`scan_ma_cross` 只判穿越,没算斜率/角度)→ 要补算。
- → 要补:`StrategyRecommendation`/`StrategySignal` 加数值字段(RSI 值 / 趋势 / pctb / 金叉角度),金叉角度补算。**中。**
