## Part 01 · 产品画像

一句话定位：面向中国散户、AI 原生、桌面 + Web 双端的 A 股专业分析终端。

| 维度 | 数据 |
|---|---|
| 市场覆盖 | 3,949+ A 股标的（沪/深/创/科） |
| 技术指标 | 70+（含 MACD/RSI/BOLL/缠论） |
| 绘图工具 | 60+（趋势线/斐波/江恩/缠论） |
| 部署形态 | Web / Windows / macOS |

### 它对标谁？

对标 **TradingView** 的图表能力 + **通达信** 的 A 股数据生态 + **同花顺/Wind** 的资讯面板，但用 AI Agent 把这些原本割裂的能力打通在一条工作流里。

- TradingView 缺：A 股数据贵 + 缠论生态弱
- 通达信缺：UI 古旧、无 Mac、回测能力弱
- Wind 机构版缺：太贵（2 万+/年）
- **观潮的空位：散户买得起的"准专业"工具**

### 它卖什么"独门"？

把分析师的整条思考链路收进同一个终端：**看图 → 验证 → 回测 → 复盘**。每一步不用切软件。

- 自研 Canvas 2D + WebGL 图表引擎（万根 K 线 60fps）
- Pine Script 策略引擎（兼容 TV 老脚本）
- 缠论自动标注（笔/段/中枢/买卖点 + 算法文档公开）
- 四 Agent 辩论（技术/基本/消息/价值面交叉质证）

## Part 02 · 四大功能模组

围绕"一条工作流"组织，每个模组都是独立产品级能力。

### Module 01 · 图表引擎

自研渲染，为金融数据而生。Canvas 2D 精细绘制 + WebGL 加速混合渲染，自适应切换。

- 8 种图表形态：K 线 / 分时 / 面积 / Renko / PnF 等
- 十字光标、缩放、滚动全局同步，多窗口协同
- 磁吸对齐到 K 线关键价位（像素级精度）
- 完整撤销/重做栈，缩略图导航万级 K 线

### Module 02 · 策略引擎

Pine Script + 沙箱回测，编写、调试、回测、参数优化一条龙，TV 脚本无缝迁移。

- Pine Script 解释器 + 通达信公式语法双兼容
- 断点 / 变量监视 / 单步执行，沙箱隔离
- 网格搜索 + 遗传算法双引擎参数优化
- Walk-Forward 向前测试 + 蒙特卡洛模拟
- 自选股池跨股扫描，批量筛策略×标的

### Module 03 · AI 研判

四个视角，一份梳理。四个 AI 角色各持己见，交叉质证后汇总结构化要点。**仅供参考，不构成投资建议**。

- 技术面 / 基本面 / 消息面 / 价值面 四 Agent
- AI 形态识别：头肩顶 / 双底 / 楔形 实时提醒
- 情绪分析：解读舆论倾向，辅助心理观察
- 综合给出"看多/看空 + 置信度%"结论卡

### Module 04 · 缠论

完整缠论，算法自动标注。笔/段/中枢/买卖点自动识别，**算法文档公开** —— 这是它最独到的差异化。

- 笔的自动划分（含包含关系 + 分型确认）
- 线段识别基于笔的特征序列
- 中枢区间自动计算与延伸
- 一/二/三类买卖点实时标注
- 多级别联立分析（大小周期共振）
- 面积法 + MACD 辅助背驰判断

## Part 04 · 资质与合规策略

这是这个项目最值得学习的部分 —— 它用最低的合规成本撑起了一个"看起来很专业"的金融工具产品。

- 大概率为：**个人开发者 + 小团队 + 个人/个体工商户备案**

### 合规边界设计

核心战略：**定位为"研究辅助工具"而非"投资顾问/证券服务"**。

- 服务条款全文反复声明"不构成投资建议"（出现 5+ 次）
- AI 输出后必带"非投资建议"小字
- 买卖点标注后注明"辅助结构复盘"
- 强制 **18+**，未成年禁止注册
- 禁止用户传播"荐股信息"或市场操纵言论
- 数据存中国境内服务器（合规存储要求）

### 关键边界：它什么都做，就是不下单

观潮做了 K 线、指标、AI 分析、策略回测、缠论、龙虎榜、新闻面板 —— 唯独 **不接入券商通道、不替用户下单、不提供资金管理服务**。

这是它能用"工具软件"身份运营、不需要券商牌照/投顾牌照/基金销售牌照的根本原因。一旦它要"自动下单"或"代客理财"，就立刻进入证监会监管范围 —— 这是 99% 的散户工具不敢碰的红线。

### 订阅条款的精细化

- **72 小时无理由退款**（冷静期）
- 30 天内开发票（电子发票，5 个工作日内）
- 自动续费默认关闭，提前邮件通知
- 价格变更前显著告知
- 已消费配额按比例抵扣

### 隐私政策合规性

- HTTPS/TLS 传输 + bcrypt 密码加密
- 数据存中国境内
- 明确列出第三方：支付宝/微信支付/Google Fonts/百度站长
- 自建匿名行为分析（不外发）
- 用户可申请删除/导出个人数据

## Part 07 · 关键风险与边界

学观潮的形，但不能学它的"无下单 = 低风险"路径 —— CryptoSharp 是下单系统，本质不一样。

### ⚠ CryptoSharp 与观潮最大的合规鸿沟

**观潮的安全感来自"不下单"**。它再怎么准、再怎么 AI，都是"建议"，用户自己去券商下单。它的法律责任停在"工具瑕疵"层面。

**CryptoSharp 不一样**。一旦帮用户下单（即使是用户自己授权的 API Key），就要面对：

1. 资金安全责任（API Key 泄露、误下单、滑点损失）
2. 反洗钱合规（KYC/AML，如果做多用户 SaaS）
3. 监管定性（在中国大陆，虚拟币交易/经纪相关服务被全面禁止；海外则要看具体司法管辖区）
4. 用户托管资金（即使不直接托管，自动交易也可能被认定为代客理财）

### 合规路径 A · 跟观潮一样做"分析工具"

把 CryptoSharp 拆成两个产品：

- **CryptoSharp Insight**（订阅产品，对标观潮）：只做分析、回测、推送，不接 API Key、不下单
- **CryptoSharp Trade**（保留给船长自己/极少数极客用户）：开源版/自托管版，用户自己装、自担风险

**优点：** 合规风险骤降，可以光明正大商业化。  
**缺点：** 砍掉了最核心的差异化能力（自动交易）。

### 合规路径 B · 走海外路线

香港 / 新加坡 / BVI / 开曼注册公司，明确禁止中国大陆用户使用：

- 注册时 IP 检测 + KYC 排除中国大陆
- 服务条款列明"不向中国大陆居民提供服务"
- 使用 Stripe / Crypto 收款，避免微信/支付宝
- 对应法域：香港 SFC / 新加坡 MAS / 美国 FinCEN

**优点：** 可以保留自动交易能力。  
**缺点：** 合规复杂度大幅上升，需要律师，可能需要牌照（看具体业务形态）。

### 务实建议

当前阶段（船长 + 少数朋友试用），**不需要立刻做合规选择题**。但需要在"开放注册"那一天之前，把这个问题想透。

最低成本的开局：先按观潮模式做 **"分析订阅产品"**，把下单功能藏在"高级用户授权后启用"的位置（且明示风险），**用户量起来再决定是否拆产品**。

3. 数据壁垒挖深：用户行为 + 信号命中率 + 策略表现 → 自有数据集
4. 增长引擎：分销 / 推荐返利 / KOL 合作（观潮没做，这是机会）

## Part 09 · 一句话总结

### 观潮给 CryptoSharp 的最大启发

**一个个人/小团队 + 一台云服务器 + 一套清晰的合规话术 + 一个"散户买得起"的定价 + 一条"看图到回测"的工作流**，就可以做出一个看起来很专业、用户愿意付费的金融分析工具产品。

它告诉你：**做散户工具，不需要先成立公司、不需要拿牌照、不需要拉投资** —— 只要边界清晰（不下单、不投顾），定价合理（¥39/月），合规话术到位（不构成投资建议），就能在 6-12 个月内验证商业化可行性。

但 CryptoSharp 比观潮难一个量级 —— 因为**下单**这个动作让它必须在某一刻面对"分析工具"还是"代客交易"的身份问题。这个问题**不会消失**，只能延后或绕开。
