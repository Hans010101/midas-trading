# 0050 · X 自动发布架子:平台勾选框架 + 硬编码白名单焊死 X(manual-first 演进而非打破)

**日期**:2026-07-08
**状态**:已定案(Hans 批准「架子早搭 + 白名单物理锁」方案 · 架子刀 PR)
**关联**:X 自动化第一步(#173 · x_short 自动起草)、X 发布接入(#169)、ADR 0049、
[[x-publish-adapter-live]]

## 背景

Hans 要把 X 纳入类币安广场的自动化管线,并给「自动托管」加**平台多选勾选开关**
(勾选的平台才自动质检发布,未来头条/小红书可扩展)。但 X 是公开平台,自动发错立刻面向
公众收不回;X 短推自动化质量 Hans 尚未充分验证。原红线:`auto_publish._PLATFORM`
硬编码 `binance_square` = 「X 绝不自动发」的物理锁。

Hans 拍板分两步:**第一步**(#173,已上线)x_short 自动起草、发布仍人工;**架子刀**(本 ADR)
把平台勾选的架构和 UI 先搭好,但 **X 的自动发布腿用硬编码白名单物理焊死**;**第二步**
(未来,需 Hans 验过质量后**明确授权**)白名单加一行 `"x"` + 后台勾选即启用,架构不动。

## 决策

1. **平台勾选配置层**(`auto_guard`):Redis 键 `x:auto:platform:{platform}`。
   自动发布 = **总开关(`x:auto:enabled`)AND 平台勾选** 双闸。
   ★默认值按平台分:`binance_square` **默认 ON**(未设 = 开,保持现状零语义变化);
   **其它平台一律默认 OFF**(判 `=="1"` 才开,绝不用 `!="0"`)——新平台加进 ADAPTERS
   **绝不自动开着发**,fail-safe 方向(Redis 丢键也回落安全侧)。

2. **★★硬编码白名单 = manual-first 的物理锁**(`auto_publish._AUTO_PUBLISH_ALLOWED`,
   现 `{"binance_square"}`):自动路径读勾选配置,但**只有白名单内的平台可能被自动发**。
   X 不在白名单 → 即便 Redis 勾选被误翻 ON / 端点被绕,自动路径也**发不出 X**
   (代码级焊死,不降级成运行时 flag)。这是 Hans 明确认可的设计:「架子早搭 + X 绝不
   意外自动发」。

3. **配置层同焊死(双保险)**:平台勾选端点 `POST /x-auto/platforms/{platform}` 对
   白名单外的平台返回 400「暂未启用」——X 连勾选值都不可写。将来白名单加 `"x"`,
   端点随之自动解锁,无需二次改动。

4. **admin UI**:自动托管面板加「自动发布平台」多选——binance 可勾/取消(新增分闸:
   取消 = 停币安自动发,总开关仍管自动起草);**X 灰显 + 「暂未启用」标**,不可点。
   平台清单从 `registry.ADAPTERS` 派生(加平台 = registry 加一行,面板自动出现)。

5. **红线表述演进**:「X 绝不自动发(硬编码单平台)」→「自动发布只可能发白名单平台;
   X 焊死在白名单外,启用需 Hans 验过 X 自动化质量后**明确授权**(= 白名单加一行 +
   勾选开启)」。红线本质(X 不会意外自动发)不变,只是把锁从「单平台常量」升级为
   「白名单 + 勾选双层」,为多平台留了门,门上仍是锁。

## 第二步启用清单(留给未来 · 须 Hans 明确授权)

启用 X 自动发布时:① `_AUTO_PUBLISH_ALLOWED` 加 `"x"`;② Hans 后台勾选 X;
③ **按既定安全设计补齐**:per-platform 熔断(现全局熔断会让 X 失败连坐币安)、
X 独立自动发布配额与频率、x_short↔platform 的选稿映射(自动发 X 应发 x_short 风格)。
①②之外的③在启用刀里做,本架子刀不预埋(避免无行为的死代码)。

## 不变量(测试钉死)

- `resolve_auto_platforms`:X 勾选被强翻 ON 时仍**只返回白名单平台**(焊死测试)。
- binance 勾选键**从未设置**(存量部署)→ 默认 ON → 自动发行为与旧 `_PLATFORM`
  硬编码**逐字节一致**(零回归测试)。
- binance 取消勾选 → `run_auto_publish` skip `no_platform_checked`(新分闸)。
- X/未知平台 toggle 端点 400;`status.platforms` 里 X `auto_allowed=False`。

## 与 #173(第一步)的关系

#173 让 x_short 自动**起草**(独立配额、发布仍人工),本架子刀管**自动发布**的平台选择。
两刀正交:x_short 永不进 `auto_publish`(#173 的 merge 纯函数钉死),即便将来白名单
加了 `"x"`,自动发 X 的选稿逻辑也是第二步启用刀的事,x_short 现有「只人工发」不受影响。
