# 0023 · A股 / 美股 首页改版方案(借用加密「列表→详情」架构 · 统一视觉)

## 状态

**Approved**(2026-05-24)· 接 0022 设计规范(阶段③ = A股/美股首页改版)。§10 八条决策已由产品方全部拍板(见下),按 §8 分期落地:**先 A股、一期一交付、feature 分支、审过再挑 main**。

---

## 背景与已定方向(产品方此前已确认)

1. A股/美股首页借用加密频道的「**列表 → 详情**」两层架构 + 视觉风格,但首页内容**不照搬「单一全市场涨幅榜」**——A股 5000+、美股上万,全市场涨幅榜参考价值有限。
2. **全产品视觉统一**:用 0022 阶段② 刚封的共用组件库(`Panel` / `DataTable` / `DirectionBadge` / `StatusPill` / `EmptyState` / `LoadingNote`)搭,不再手搓。
3. 详情页:K线 / 缠论 / AI 决策卡 **复用**;右侧下单区**差异化**:
   - **A股 = 纯现货做多**(复用 0008 现货虚拟交易引擎 · 无杠杆 / 无做空 / 无强平)
   - **美股 = 买入做多 + 卖空 · 但无杠杆**(不是加密合约那套)
   - **绝不照搬加密的杠杆 / 保证金 / 强平**(红线)

## §0 现状摸底(数据可行性的前提 · 实读源码)

| 能力 | A股(cn_source · AKShare)| 美股(us_source · yfinance)|
|---|---|---|
| K 线 | ✅ 有(Sina 日 K + EM 分钟 K)| ✅ 有(yfinance history)|
| 标的清单 | ✅ `stock_info_a_code_name`(全 A 股代码+名)| ⚠️ 写死 demo 列表(yfinance 无「列全市场」API)|
| **大盘指数** | ❌ 未实现(AKShare 可:`stock_zh_index_spot_em` / `stock_zh_index_daily`)| ❌ 未实现(yfinance 可:`^DJI/^IXIC/^GSPC/^RUT` 当指数标的拉)|
| **全市场实时快照 / 榜单** | ❌ 未实现(AKShare 可:`stock_zh_a_spot_em` 一次返全市场,含涨跌幅/成交额/换手/量比/振幅)| ❌ 无(**yfinance 无 screener / 批量榜单 API** — 关键缺口)|
| **涨跌家数 / 涨跌停** | ❌ 未实现(AKShare 可:spot 快照聚合算涨跌家数 + `stock_zt_pool_em`/`stock_zt_pool_dtgc_em` 涨跌停池)| ❌ 无现成 |
| **行业 / 概念板块** | ❌ 未实现(AKShare 可:`stock_board_industry_name_em` + 成分)| ❌ 无现成(需策展清单)|
| **盘前盘后** | N/A(A股无盘前盘后)| ⚠️ yfinance `fast_info`/`info` 有 pre/post price,质量/延迟参差 |
| 现有接口 | 仅 `GET /market/kline` + `/market/symbols`(无 overview/榜单/指数)| 同左 |

**结论**:A股/美股首页要的**指数 / 榜单 / 板块 / 涨跌家数 数据,现在 100% 没有**(现有 cn/us 只采 K 线)。要全部**新增:采集任务(Celery)+ 存储(ClickHouse 快照表,类比 `crypto_ticker_24h` / `crypto_market_overview`)+ 只读接口(类比 `/crypto/overview` / `/crypto/tickers/24h`)**。
- **A股**:AKShare(已是依赖)函数齐全,**可行性高**,但工作量是从零搭采集→存储→接口→前端。
- **美股**:yfinance **缺 screener / 批量榜单**——这是**最大可行性风险**(详见 §5 + §10 决策⑥)。

## §1 A股首页布局建议

走「市场首页(列表/总览)→ 详情页」。`Panel` + `DataTable` 搭,视觉对齐加密频道。
- **大盘指数卡**(横排 4 张 `Panel`):上证综指 / 深证成指 / 创业板指 / 沪深300 · 点数 + 涨跌点 + 涨跌幅(`up/down` 语义色)。
- **市场情绪条**:涨家数 / 跌家数 / 平家数(红绿对比条)+ 涨停数 / 跌停数 + 总成交额。
- **多榜单 Tab**(手搓 tab 收口为统一 tab 样式):涨幅 / 跌幅 / 成交额 / 换手率 / 量比 —— 每个 Tab 一张 `DataTable`(代码/名称/现价/涨跌幅/对应指标),点行进详情页。
- **热门板块 / 行业**:行业板块涨幅榜(`DataTable` 或卡片网格),点板块可下钻成分股(可选二期)。

## §2 美股首页布局建议

同两层架构。
- **大盘指数卡**:道指(^DJI)/ 纳斯达克(^IXIC)/ 标普500(^GSPC)/ 罗素2000(^RUT)。
- **多榜单 Tab**:涨幅 / 跌幅 / 成交额 / 盘前盘后异动 —— **依赖标的池**(见 §5,yfinance 无全市场榜单)。
- **行业板块** + **中概股板块**:均需**人工策展标的清单**(中概股清单 + 行业代表股)。
- ⚠️ 美股榜单的「全市场」是受限的(只能覆盖策展池),首页要诚实标注「热门美股 / 重点关注池」而非「全市场榜」。

## §3 非交易时段处理

首页顶部 + 每个榜单显式标**市场状态**,避免用户误以为实时:
- 状态机:`休市(节假日)` / `盘前` / `盘中` / `盘后` / `已收盘`。
- A股时段(CST):9:30–11:30 / 13:00–15:00,其余「已收盘 / 休市」。
- 美股时段(对国内 = 夜间,含夏令时):盘前 / 盘中(约 21:30–04:00 CST,DST 偏移)/ 盘后。
- 榜单数据带「**截至 收盘/HH:MM**」时间戳;非盘中时榜单为快照,明确标注。
- 需:**交易日历 / 节假日**(A股 AKShare `tool_trade_date_hist_sina`;美股需日历源或硬编码节假日)+ 时段判断工具(后端算状态、前端展示)。

## §4 详情页右侧下单区差异化(核心红线)

复用 K线/缠论/AI卡;**右侧下单区按市场分**:

| 市场 | 下单能力 | 引擎 | 改动 |
|---|---|---|---|
| **A股** | 纯现货**做多**(买入 / 卖出平仓)· 无杠杆/做空/强平 | **直接复用 0008 现货引擎**(VirtualPosition/Order)| 零引擎改动 · 复用现有 workbench 下单 UI · 可选加 A股提示(T+1 / 涨跌停,虚拟教学可简化或仅提示)|
| **美股** | 买入**做多** + **卖空** · **无杠杆** | 0008 现货引擎 + **需扩展卖空** | ⚠️ 卖空 = 允许负持仓 + 平空(买回)· **无杠杆 → 不涉及保证金/强平**(比 perp 简单很多)· 但仍需小心扩展 0008 引擎,不碰已上线的现货做多 |

- 🔴 **绝不引入** 加密的杠杆 / 保证金 / 强平 / 资金费。
- 美股卖空是**唯一需要后端引擎扩展**的点(见 §10 决策③)。

## §5 数据来源逐项可行性(方案可行性关键)

| 数据 | A股 | 美股 |
|---|---|---|
| 大盘指数 | ✅ AKShare 现成,补采集即可 | ✅ yfinance 把指数当标的拉,现成 |
| 涨幅/跌幅/成交额/换手/量比榜 | ✅ AKShare `stock_zh_a_spot_em` 一次返全市场全字段,排序即得;补采集+接口 | ❌ **yfinance 无 screener**;只能「策展池 + 逐个拉报价排序」(量大慢、覆盖有限)或**引入新数据源** |
| 涨跌家数 / 涨跌停 | ✅ spot 快照聚合 + AKShare 涨跌停池 | ⚠️ 策展池内可算「涨跌家数」,但非真全市场 |
| 行业 / 概念板块 | ✅ AKShare 板块函数现成 | ❌ 需策展清单(行业代表股 + 中概股清单) |
| 盘前盘后 | N/A | ⚠️ yfinance pre/post 有但质量参差 |
| 交易日历 | ✅ AKShare | ⚠️ 需日历源 / 硬编码 |

**要补的(逐项)**:
- A股:`stock_zh_a_spot_em`(全市场快照 → 榜单 + 涨跌家数)· 指数 spot/daily · 涨跌停池 · 行业板块 —— 4 类新采集 + CH 表 + 接口。**全部 AKShare 可撑**。
- 美股:指数(yfinance OK)· **榜单/板块 = 受限**(策展池 + 批量拉,或新数据源)· 交易日历。
- 两市场都需:Celery 采集任务(交易时段才跑)+ ClickHouse 快照/榜单表 + `/cn/*`、`/us/*` 只读接口 + 市场状态接口。

## §9 风险点

1. **美股榜单数据源**(yfinance 无 screener)—— 最大风险,可能需付费源或接受受限榜单(决策⑥,涉及钱)。
2. **A股全市场 spot 采集**:5000+ 标的,`stock_zh_a_spot_em` 一次返全量(可接受);但只在 A股交易时段有意义,需时段调度。
3. **美股卖空引擎扩展**:改 0008 现货引擎,务必不碰已上线的现货做多逻辑(单独测试 + 零回归)。
4. **数据实时性 vs 非交易时段**:必须标注清楚状态 + 数据时间戳,否则用户误判。
5. **交易日历 / 节假日**:A股/美股节假日,影响状态机准确性。
6. **采集量 / 上游限流**:A股 spot 高频 + 美股批量拉,需错峰 + 时段限制(参考加密采集错峰经验)。

## §10 产品方最终决策(2026-05-24 全部拍板 · Approved)

1. **A股榜单 Tab**:**全做** —— 涨幅 / 跌幅 / 成交额 / 换手率 / 量比。
2. **板块维度**:A股行业板块**做**;美股行业板块 + 中概股板块**做**。中概股清单先用一份公开的常见名单(阿里 / 拼多多 / 京东 / 网易 / 百度 等主流)起步,后续产品方再调整。
3. **美股卖空规则**:策展股票池内的股票**都可做空**,**无杠杆(1:1)**。实现:扩展 0008 现货引擎支持「负持仓 + 平空(买回)」,🔴 **绝不修改已上线的现货做多逻辑** —— 卖空作为新增能力单独测试,确保现货做多零回归。
4. **官网首页**:**保留** `app/page.tsx` 营销首页;A股/美股市场页**新建独立路由**(`/cn-market`、`/us-market`,类比 `/crypto-market`)。默认落地仍为营销页。
5. **A股/美股详情页**:**新建**类 `crypto-preview` 的详情页(架构对齐加密);`/workbench` 保留作「自选盯盘」。
6. **美股榜单数据源**:走**策展股票池**(标普500成分股 + 中概股 + 热门科技股),🔴 **不引入付费数据源**。榜单 = 策展池内排行,首页诚实标注「热门美股 / 重点关注池」而非「全市场榜」。(已评估 StockSharp:C#/.NET 算法交易平台、定位真实交易,与本产品技术栈 + 虚拟资金红线均不符,不采用。)
7. **市场优先级**:**先做 A股**(AKShare 数据齐全),美股随后。
8. **涨跌色开关**:入口放**设置页**,默认**红涨绿跌**。
