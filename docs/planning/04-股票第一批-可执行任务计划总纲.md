# 股票模块优化 · 第一批 · 可执行任务计划总纲

> 基于《三功能详细规划》(已通过)+ Hans 已拍板的 6 个决策固化。**规划性质,不写功能代码、不碰开发分支(PR-8 不动)。**

## 一、Hans 已拍板的 6 个决策(固化)

| # | 决策 | 对计划的影响 |
|---|---|---|
| 1 | 功能2(条件单)已就绪:真机验证 cn/us/hk 各挂一笔正常即勾掉,不额外打磨 | 降为「第0步验证刀」,Hans 执行 |
| 2 | 筛选器第一版条件 = 现成(RSI区间/均线排列/涨跌幅/价格)+ 穿越类(MACD金叉/KDJ金叉/布林带宽/量比);**缠论完整放第二版(1c)** | 功能1 拆 1a/1b,缠论入 1c |
| 3 | 性能:先轻量预筛(A)+ 按需批量算指标(C·`select_klines_batch`);**指标快照表(B)中期优化,不在第一批** | 1a 用 A,1b 用 C,B 不做 |
| 4 | 筛选器加密现货:第一批只做股票,加密后续复用 | 筛选器范围 = cn/us/hk 现货 |
| 5 | 港股告警 8 指标子集(price/涨跌幅/量/MA/MACD/RSI/布林/宽度);**恒指告警不做** | 功能3 范围锁定,无恒指 |
| 6 | ★港股 K线源深度 = 功能1+3 共同硬前置,必须先复核 | 设独立「前置任务」,阻塞港股部分 |

## 二、执行顺序总览

```
前置(Code·最先)  港股K线源深度复核 ──┬─→ 阻塞 功能3 港股告警范围
                                      └─→ 阻塞 功能1 港股技术筛选范围

第0步(Hans·并行)  功能2 条件单真机验证 ──→ 通过即勾掉

第1步(Code)       功能3 港股告警(按前置结论定范围)

第2步(Code·主力)  功能1 筛选器  1a MVP → 1b 穿越类 → 1c 缠论+性能深化
                                  (每子阶段独立可交付)
```

- **前置**与**第0步**可并行(一个 Code 只读核查、一个 Hans 真机点)。
- 功能3、功能1 都依赖前置港股结论(功能1 的股票部分中 cn/us 不依赖,港股筛选依赖)。

## 三、前置任务 · 港股 K线源深度复核(★硬前置)

| 项 | 内容 |
|---|---|
| **谁做** | 开发 Code(只读核查 + 生产数据确认) |
| **工作量** | 低(~0.5d) |
| **依赖** | 无(最先做) |
| **为什么硬前置** | 现状盘点说港股 K线深度 ~18 根(yfinance 备用源),三功能深挖说主源新浪日线深度充足——**冲突未决**。这个结论直接决定港股能否做技术指标筛选/告警(MA/MACD/RSI 需 20-60 根) |
| **具体核查** | ① 生产实际用哪个港股 K线源(新浪 `stock_hk_daily` 主源 vs yfinance 备用)② 实际能取到多少根日线深度(查 `hk_kline_probe` 结论 + 生产 ClickHouse `kline` 表 market=hk 实际行数)③ 覆盖多少标的(策展 ~18 vs 榜单 ~900) |
| **产出物** | 一句话结论:港股技术指标筛选/告警**可做到什么程度**——(a) 深度够(≥60 根)→ 8 指标全可做;(b) 只有 ~18 根 → 港股只能做价格/涨跌幅/成交额类,技术指标(MA/MACD/RSI/布林)降级或等源升级 |
| **验证方式** | Code 直接查生产 ClickHouse + 代码,出结论给 Hans |
| **复用基建** | 只读现有数据/代码,零改动 |
| **红线** | N/A(纯只读核查) |
| **★阻塞** | 结论出来前,功能3 的技术指标部分 + 功能1 的港股技术筛选**范围不能定** |

## 六、第2步 · 功能1 筛选器(主力 · 分 3 子阶段 · 每阶段独立可交付)

### 1a · MVP(现成条件 + 轻量预筛)

| 项 | 内容 |
|---|---|
| **谁做** | 开发 Code |
| **工作量** | 中 |
| **依赖** | 前置(港股部分);cn/us 不依赖 |

| **碰哪些文件** | 后端:新增 `POST /api/v1/{market}/screener`(预筛端点)+ 筛选服务(复用 `indicators.py` + spot 快照查询);前端:新增筛选页(复用 `market-home/*-sections` 榜单/搜索/跳详情范式) |

## 九、风险 / 未决项

1. **★港股 K线源深度(未决)**:阻塞功能3 技术指标 + 功能1 港股技术筛选范围,**必须前置复核清楚**。结论前港股技术类范围标"待定"。
2. **性能边界**:1a 轻量预筛秒级无忧;1b 全市场指标筛选靠"预筛→候选→批量算",若用户筛"全市场 RSI"(无快照预筛维度)可能慢——1b 要确保技术指标条件**总是先用快照预筛缩小候选集**,再批量算指标。
3. **美股策展池**:筛选范围仅 ~128 只(产品定位),非全市场,需在 UI 诚实标注。
