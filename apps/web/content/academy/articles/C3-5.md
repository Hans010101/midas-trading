# C3-5 布林带策略：均值回归与突破的两种用法

> 点金训练营 · C3 策略专题库

布林带是个"一图两用"的指标——既能用于震荡市的均值回归，又能用于变盘时的突破。这一篇讲清它的定义、两种用法和适用边界。

**本篇速览**

- 布林带：**中轨 = 移动平均（20）、上/下轨 = 中轨 ± K 倍标准差（K=2、对称）**；随波动"呼吸"。
- 两种用法：**均值回归（震荡市：触上轨偏高/触下轨偏低、回归中轨）** 与 **突破（收口后开口突破、启动趋势）**；**先判断环境再选用法**。
- ★最大坑：**强趋势里用均值回归会失效**（价格沿轨走不回归）；**触轨是位置参考、不是反转信号**。
- ⚠️ 点金虚拟盘可试/回测，AI 信号仅供参考；信号为参考、非指令、不预测、无稳赚。

## 一、策略原理

布林带（BOLL）由三条轨道构成（见 B7，★定义务必准确）：

- **中轨 = 移动平均线**（常用 20 周期）；
- **上轨 / 下轨 = 中轨 ± K 倍标准差**（K 常用 **2**），**对称**分布在中轨两侧。

**标准差反映波动**：波动大、通道就宽；波动小、通道就窄——所以布林带会随行情"**呼吸**"（开口/收口，见 B8）。价格大部分时间在通道内运行（倾向、非铁律）。

布林带策略，就是利用"价格相对通道的位置"和"通道的宽窄变化"来辅助决策。它有**两种几乎相反的用法**，对应不同环境。

## 二、适用场景与失效场景

布林带的关键，是**先判断环境、再决定用哪种用法**：

- **均值回归用法 → 适用震荡市**：震荡里，价格触上轨偏高、触下轨偏低，有向中轨回归的倾向。
- **突破用法 → 适用收口后变盘**：长时间收口（波动收敛）后开口、价格突破轨道，可能启动一段趋势。
- ★**失效（最大坑）：强趋势里用"均值回归"。** 强趋势中价格会**沿着上轨（或下轨）一路走**、并不回归中轨——这时如果你"触上轨就做空、触下轨就做多"，会被趋势反复打脸。

## 三、怎么用（两种用法）

**用法一·均值回归（震荡市）：**
- 价格触及/接近**上轨** → 偏高的参考（震荡里可能回落向中轨）；
- 价格触及/接近**下轨** → 偏低的参考（震荡里可能回升向中轨）；
- ⚠️ **触轨是"位置参考"，不是"反转信号"**——强趋势会沿轨走，必须配合环境判断和止损。

**用法二·突破（变盘）：**
- **收口**（上下轨收窄）= 波动收敛，常"酝酿变盘"；
- 收口后**开口 + 价格突破轨道** → 可能启动趋势（顺突破方向参考，呼应 C3-4）；
- ⚠️ 收口之后**方向无法预测**——它提示"要变盘"，不提示"往哪变"。

## 四、优缺点与风险

**优点**：**直观**（价格相对通道一目了然）；**自适应波动**（通道会呼吸）；**一图两用**（回归 + 突破）。

**缺点与风险**：

- ★**用错环境就用反**：在强趋势里用均值回归（触上轨做空）、或在震荡里用突破（追假突破），都会亏——**布林带策略成败，一半在"判断对环境"**；
- **触轨 ≠ 反转**：最常见的误用，把"触上轨"当成"必跌"；
- **不保证盈利**。
