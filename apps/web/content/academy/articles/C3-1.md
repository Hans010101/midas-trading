# C3-1 均线策略：金叉死叉与多头排列，趋势跟踪的基础

> 点金训练营 · C3 策略专题库

均线策略是最古老、最广为人知的趋势策略，几乎是每个交易者的入门第一课。这一篇按"原理 → 适用/失效 → 用法 → 优缺点风险 → 怎么在点金里试"的结构，把它讲透——重点不是"用它能不能赚"，而是**它的逻辑和适用边界**。

## 一、策略原理

均线（MA）是**最近 N 个周期收盘价的平均值，滚动连成线**（见 B1）。它把价格的短期波动"抚平"，让你更清楚地看到趋势方向。

均线策略的核心逻辑就一句话：**用均线的方向、交叉、排列来判断趋势，然后顺着趋势做。** 它不预测顶底，只跟随已经形成的趋势。

## 二、适用场景与失效场景

- **适用：单边趋势行情。** 价格有明确方向（持续上涨或下跌）时，均线能很好地跟随趋势、过滤噪音，让你"待在趋势里"。
- **失效：震荡行情。** 价格在区间里来回时，均线会**频繁地金叉、死叉、再金叉**——产生大量**假信号**，让你追涨杀跌、反复止损（呼应 C2-5）。

**一句话：均线策略是"趋势的朋友、震荡的敌人"。** 用之前，先判断现在是不是趋势行情。

## 三、怎么用（信号与规则）

均线策略常用三类信号（都是**参考、不是买卖指令**）：

1. **金叉 / 死叉**（双均线）：
   - **金叉 = 短期均线从下向上穿过长期均线**，偏多参考；
   - **死叉 = 短期均线从上向下穿过长期均线**，偏空参考（方向绝不能记反，见 B2）。
2. **多头 / 空头排列**（多均线系统，见 B3）：
   - **多头排列**：从上到下 = 价格 > 短期 > 中期 > 长期 → 强势上涨结构，倾向持有；
   - **空头排列**：从上到下 = 长期 > 中期 > 短期 > 价格 → 弱势下跌结构，倾向回避。
3. **均线方向**：均线向上偏多、向下偏空、走平震荡。

实战中常把"金叉 + 多头排列"作为偏多的结构性参考、"死叉 + 空头排列"作为偏空参考，并配合止损使用。

## 四、优缺点与风险

**优点**：简单直观、广为人知；能帮你**抓住主升/主跌段**、过滤短期噪音；规则清晰、易于执行和回测。

**缺点与风险**：

- **滞后**：均线是对过去价格的平均，**交叉信号出现时，价格往往已经走了一段**——你买在金叉、卖在死叉，注定不是最低/最高点；
- **震荡里假信号多**：这是均线策略最大的痛点（见上）；
- **不保证盈利**：它是趋势参考，趋势可能随时反转、可能假突破；**没有任何均线参数能稳赚**。

## 五、怎么在点金里试（虚拟盘）

- 在点金的**全程虚拟**环境里，用虚拟盘按均线信号（金叉/死叉、多头排列）做练习，亲身体会它在趋势里好用、在震荡里被反复打脸；
- 用**策略研究室回测**不同均线参数（如 5/20、20/60）在历史行情里的表现，重点看**最大回撤和盈亏比**，别只看收益（回测有效≠未来有效，见 F18）；
- 点金的 **AI 策略信号仅供参考**——和你自己的判断对照，不要当成买卖指令照搬。

> ⚠️ 点金全程虚拟，所有分析与 AI **仅供参考、不构成投资建议、不预测**；回测/虚拟成绩不代表真实结果。

## 六、本篇要点

- 均线策略 = **用均线方向/交叉/排列判断趋势、顺势而为**；不预测顶底，跟随已形成的趋势。
- **适用单边趋势、失效于震荡**（震荡里金叉死叉假信号多）。
- 信号：**金叉=短期均线上穿长期（偏多）、死叉=短期下穿长期（偏空）**；多头排列=价>短>中>长（强势）；均为**参考、非指令**。
- 优点简单能抓趋势；缺点**滞后 + 震荡假信号多 + 不保证盈利**。
- ⚠️ 点金虚拟盘可试/回测，AI 信号仅供参考；无稳赚参数、不预测。
