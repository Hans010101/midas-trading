# 多均线系统：多头排列与空头排列

> 点金训练营 · 第二阶 · 模块6 经典技术指标

**本篇速览**

- **多均线系统**：同时使用短 / 中 / 长几条均线，用排列顺序判断市场强弱。
- **多头排列**：从上到下 = 价格 > 短期 > 中期 > 长期（短在上、价在最上），代表强势上涨结构。
- **空头排列**：从上到下 = 长期 > 中期 > 短期 > 价格（短在下、价在最下），代表弱势下跌结构。
- **排列转换**（纠缠后反向排列）提示趋势可能变化，但不等于一定反转，且有滞后性，仅作参考。

## 一、概念引入：不止看一条均线

前面我们用的是一条或两条均线。实际中，很多交易者会**同时挂上短期、中期、长期好几条均线**——这就是"多均线系统"。

为什么要这么做？因为多条均线一起看，能同时呈现"短、中、长不同时间维度的力量状态"，而它们的**排列顺序**，可以非常直观地反映当前市场是强是弱。这一篇就讲两种最典型的排列：多头排列和空头排列。

## 二、多头排列：均线从上到下"短中长"，价格在最上

**多头排列**，描述的是一种典型的**强势（上涨）结构**。它的特征是，从图上**从上到下**依次排列为：

**价格（最上）→ 短期均线 → 中期均线 → 长期均线（最下）**

也就是说：短期均线在上、长期均线在下，几条均线像扇形一样向上张开，而价格运行在所有均线的**上方**。

为什么这代表强势？回忆"均线 = 平均成本"：

- 短期均线 > 中期 > 长期，说明**越近期买入的人，平均成本越高**——人们愿意不断用更高的价格买入。
- 价格在所有均线上方，说明**各个时间段的持有者基本都处于浮盈**。

这正是一个健康上涨趋势的样子：买方持续占优，重心节节抬高。

## 三、空头排列：均线从上到下"长中短"，价格在最下

**空头排列**是多头排列的镜像，描述一种典型的**弱势（下跌）结构**。从图上**从上到下**依次排列为：

**长期均线（最上）→ 中期均线 → 短期均线 → 价格（最下）**

也就是说：长期均线在上、短期均线在下，均线向下张开，价格运行在所有均线的**下方**。

含义同样可以用平均成本理解：短期均线 < 中期 < 长期，说明**越近期买入的人成本越低**——价格在不断走低；而价格在所有均线下方，说明**持有者普遍浮亏**。这是一个弱势下跌趋势的典型形态。

把两者对照记忆：

- **多头排列**：短期在最上、长期在最下，价格在最上方 → 强势上涨结构。
- **空头排列**：短期在最下、长期在最上，价格在最下方 → 弱势下跌结构。

## 四、排列的转换：趋势可能正在变化

均线排列不是一成不变的。当一个趋势的力量开始衰竭、可能转向时，原本整齐的排列会先变得**纠缠、粘合**（几条均线挤在一起、互相交叉），然后**重新排列成相反的顺序**。

比如：从多头排列 → 均线纠缠粘合 → 逐渐变成空头排列，往往**提示原来的上涨趋势可能正在转弱或改变**。

但务必注意两点：

1. **"提示可能变化"不等于"一定反转"。** 均线纠缠后，既可能转向，也可能只是中途震荡一下、又恢复原排列。它是一个观察线索，不是预测结论。
2. **同样有滞后性。** 和金叉死叉一样，多均线系统基于历史价格，排列的变化也滞后于价格本身。

所以，多均线排列适合用来**描述和确认当前的市场状态（强 / 弱 / 转换中）**，而不是用来预言未来，或作为单独的买卖依据。
