# 缠论是什么：一套完整的市场分析体系

> 点金训练营 · 第三阶 · 模块9 缠论入门

**本篇速览**

- 缠论是一套用**严格几何结构**分解、描述价格走势的分析体系，源于笔名"缠中说禅"的网络连载。
- 核心结构由小到大：**分型 → 笔 → 线段 → 中枢**，并具有**级别递归**的特性。
- 与传统技术分析相比，缠论强调**几何结构、完全分类（趋势 / 盘整）、级别递归**。
- 缠论**体系庞大、有学习门槛**，且是**分析工具而非预测神器**——不神化、不承诺稳赚。

## 一、概念引入：从"看指标"到"看结构"

学到这里，你已经认识了均线、MACD、布林带、RSI 等技术指标。它们大多是"在价格之上叠加一个计算值"来辅助判断。而**缠论**提供了一个很不一样的视角：它不依赖某个指标，而是**用严格的几何结构，把价格走势本身一层层拆解、描述清楚**。

缠论是中文交易圈影响很大、也颇具争议的一套分析体系。它体系庞大、逻辑自洽，但也因此有不低的学习门槛。这一篇先讲清楚：缠论是什么、它从哪来、和普通技术分析有什么不同。

## 二、缠论的来源

缠论源于一个网络连载：作者以笔名 **"缠中说禅"** 在博客上发表的一系列文章（其中讲交易的部分常被称为《教你炒股票》系列）。这些文章后来被读者整理、统称为"缠论"。

需要说明的是：**"缠中说禅"是作者的笔名**，缠论最初是以网络博客连载的形式问世的。本训练营介绍的是这套分析方法本身的核心概念，不涉及对作者身份的考据。

## 三、缠论的核心理念：用几何结构分解走势

缠论最核心的特点，是**把杂乱的价格走势，分解成一套层层递进的几何结构单位**。从小到大，大致是这样一个递进关系：

**分型 → 笔 → 线段 → 中枢**

- **分型**：由三根（经过处理的）K 线构成的最小转折结构，标记局部的顶或底。
- **笔**：连接相邻的一个顶分型和一个底分型，是最基本的走势单位。
- **线段**：由若干笔（至少三笔）构成的更高一级走势。
- **中枢**：由连续三段走势的重叠区间构成，是缠论里非常核心的概念。

这套结构有一个重要特性——**级别递归**：同样的结构（分型、笔、中枢……）会在不同的时间级别上**重复出现**。小级别的结构组合成大级别的结构，就像把同样的积木在不同尺度上反复搭建。这让缠论能够在多个级别上、用同一套语言去描述走势。

## 四、和普通技术分析有什么不同

缠论和我们前面学的技术指标，思路差别很大：

- **传统技术分析**：更多依赖**指标**（均线、MACD、RSI 等）和**经典形态**，带有较强的统计和经验色彩。
- **缠论**：强调用**严格的几何结构**来描述走势，并追求一种叫**"完全分类"**的目标——即试图把所有可能的走势，**穷尽地归类**为有限的几种类型（核心是"趋势"和"盘整"两大类）。配合级别递归，缠论试图给走势一个结构化、系统化的描述框架。


![C1 配图2](/academy-img/C1-配图2.png)


简单说：传统指标更像"给价格做体检的若干项指标"，缠论更像"给价格画一套完整的解剖结构图"。

## 五、适用范围与学习难度（务必理性看待）

缠论作为一套分析框架，理论上可用于任何有连续价格、能画出 K 线的市场。但有两点必须说在前面：

1. **它体系庞大、有学习门槛。** 分型、笔、线段、中枢、走势级别、背驰……概念环环相扣，需要**循序渐进**地理解，不能指望速成。
2. **它是分析工具，不是预测神器。** 这一点极其重要：缠论能帮你**结构化地描述和理解走势**，但它**不能保证预测未来、更不能保证盈利**。市面上"学会缠论就能稳赚 / 精准抄底逃顶"的说法，都是夸大和误导。
