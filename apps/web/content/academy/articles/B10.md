# KDJ 指标:随机指标的三条线

KDJ 又叫随机指标(Stochastic Oscillator),用来衡量当前收盘价在最近一段价格区间里的相对位置。它由 K、D、J 三条线组成,既能看超买超卖,也能看交叉信号,是震荡类指标里最常被用到的之一。

## KDJ 是怎么算出来的

KDJ 的计算分三步:先算 RSV,再平滑出 K、D,最后放大成 J。

**第一步:RSV(未成熟随机值)**

`RSV = (C − Lₙ) / (Hₙ − Lₙ) × 100`

其中 C 是当日收盘价,Lₙ、Hₙ 是最近 n 天(常用 n=9)的最低价和最高价。RSV 衡量的是收盘价在近 n 天高低区间里的位置:收盘越贴近区间顶部,RSV 越高(接近 100);越贴近底部,RSV 越低(接近 0)。

**第二步:K 与 D**

- `K = SMA(RSV, 3)`:对 RSV 做 3 周期平滑,比 RSV 平稳一些。
- `D = SMA(K, 3)`:对 K 再平滑一次,比 K 更慢、更稳。

**第三步:J**

`J = 3K − 2D`

J 把 K 与 D 的偏离放大,是三条线里最敏感的,常常率先转向。

常用参数是 (9, 3, 3),也就是 RSV 取 9 天、K 和 D 各做 3 周期平滑。

## 怎么读 KDJ

### 超买与超卖

K、D 运行到 80 以上,通常视为超买区;到 20 以下,视为超卖区。

但要记住:**超买不等于「该卖」、超卖不等于「该买」**。这只是描述价格在近期区间里的位置,是一种参考,不是反转信号。原因见下面的「钝化」。

### 金叉与死叉

- **KDJ 金叉**:K 线上穿 D 线 → 看涨参考。
- **KDJ 死叉**:K 线下穿 D 线 → 看跌参考。

注意这是 K 与 D 两条线的交叉。它和「均线金叉」(两条价格均线,如 MA5 上穿 MA20)、「MACD 金叉」(DIF 上穿 DEA)都不一样——三者都叫「金叉」,但判定的是完全不同的线。KDJ 的金叉死叉是对结构的描述,是参考,不是买卖指令。

### J 值的特点

J 最敏感,常常领先 K、D 转向。一个容易让人误会的点是:**J 值可以超过 100、也可以低于 0**。K 和 D 被限制在 0~100 之间,但 J 是 `3K − 2D` 的放大计算,会冲出这个区间——这是正常现象,不是数据出错。

## 两个常见陷阱

### 钝化

在强趋势里,KDJ 会长期贴在超买区(持续上涨)或超卖区(持续下跌)反复运行,这叫钝化。此时「超买」可能持续很久、价格还在涨,「超卖」也可能持续很久、价格还在跌。

**钝化不代表立即反转。** 把超买超卖当成机械的反转信号,在单边行情里会反复挨打。这一点和 RSI 的钝化是同样的道理。

### 信号是参考,不是指令

KDJ 的金叉、死叉、超买、超卖,都是对价格结构的描述,是分析参考,不是买卖指令。任何单一指标都不构成完整的交易依据,也没有「必胜」的用法;指标需要结合趋势、其它工具和风险控制一起看。

## 小结

KDJ 用 RSV 衡量收盘价在近期高低区间里的位置,经两次平滑得到 K、D,再用 J 放大敏感度(常用参数 9,3,3)。读它时记住三件事:

- 超买超卖是位置参考,不是反转信号;
- 强趋势里会钝化,贴在超买/超卖区不代表马上反转;
- J 冲出 0~100 是正常的。

最后别忘了:KDJ 金叉、均线金叉、MACD 金叉是三个不同的「金叉」,判定的线各不相同,不要混为一谈。
