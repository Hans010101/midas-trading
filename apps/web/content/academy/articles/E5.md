# 持仓量（OI）：合约市场的资金温度计

> 点金训练营 · 第四阶 · 模块12 合约与衍生品

## 一、概念引入：市场里"押了多少钱"

价格告诉你"现在多少钱"，成交量告诉你"成交了多少"，而**持仓量（OI，Open Interest）**告诉你一件不同的事：**此刻市场上还有多少合约没有平仓、仍在"押注"中。** 它像一支"资金温度计"，反映合约市场的参与体量。

## 二、持仓量是什么：未平仓合约的总量

**持仓量（OI）指的是，市场上当前所有【尚未平仓】的合约的总数量。**

注意它和成交量的区别：

- **成交量**：一段时间内成交了多少（是"流量"，每个周期重新计）。
- **持仓量**：当前还有多少仓位没平掉（是"存量"，持续累计的未平仓总量）。

一笔新的开仓会让 OI 增加，一笔平仓会让 OI 减少。

## 三、OI 变化的含义：增仓与减仓

OI 的增减，反映资金是在"进场"还是"离场"：

- **OI 增加（增仓）**：有新的仓位在建立，通常意味着**新资金进场**、参与度上升。
- **OI 减少（减仓）**：有仓位在了结、平掉，意味着**资金在离场**、参与度下降。

OI 本身不分好坏，它只是告诉你"市场的参与体量在变大还是变小"。

## 四、OI 与价格配合看（量价关系）

把 OI 的变化和价格的涨跌放在一起，是常见的**参考性**观察角度。以下是几种常被讨论的组合（请注意：这些是**参考解读，不是预测、不是买卖信号**）：

- **价格上涨 + OI 增加**：上涨伴随新资金进场，常被解读为上涨有新增力量参与。
- **价格上涨 + OI 减少**：上涨可能更多来自原有空头平仓（回补），而非新资金推动。
- **价格下跌 + OI 增加**：下跌伴随新仓位建立，常被解读为有新增力量参与下跌。
- **价格下跌 + OI 减少**：下跌可能更多来自原有多头离场了结。

![E5 配图3](/academy-img/E5-配图3.png)

这些组合只是帮助你**多一个观察维度**，理解价格变动背后"是新资金进场还是旧仓位了结"。它们**有局限、会有例外，绝不能当成涨跌的预测或操作依据**，必须结合价格、其他信息综合判断。

## 五、OI 是参考数据，不是信号

必须明确：**持仓量是一种分析参考数据，不是买卖信号，更不预测价格。** OI 增加不等于"该买"，减少也不等于"该卖"——它只是描述市场参与体量的变化。它是合约分析里一个有用的观察维度（点金的合约维度图也会展示 OI 这类数据，用于分析参考，**不构成投资建议**）。

## 六、本篇要点

- **持仓量（OI）= 市场上尚未平仓的合约总量**，反映合约市场的参与体量（"存量"，区别于成交量这个"流量"）。
- **OI 增加 = 增仓（新资金进场）；OI 减少 = 减仓（资金离场）**。
- OI 与价格配合可作**参考解读**（新资金进场 vs 旧仓位了结），但有局限、有例外，**不预测、不是信号**。
- 它是合约分析的一个**参考维度**，不构成任何操作建议。
