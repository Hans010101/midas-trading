# C3-7 均值回归策略：价格回归均值的逻辑与适用边界

> 点金训练营 · C3 策略专题库

"涨多了会跌、跌多了会涨"——这是均值回归策略的朴素直觉。它在震荡市里很有用，但在趋势市里可能是**灾难**。这一篇讲清它的逻辑和那条生死边界。

**本篇速览**

- 均值回归 = **赌"价格过度偏离均值后会回归"、做反向**（与趋势跟踪相反）；本质是**区间/震荡思维**。
- **适用震荡市/有明确均值中枢、失效于趋势市**；★趋势里逆势做均值回归 = **接飞刀**（最致命风险）。
- 做法：用**均线/布林带/乖离率**衡量偏离 → 偏离过大反向参考 → **必须设止损**（防"不回归"）。
- 优点震荡里胜率高；缺点**趋势里灾难 + 接飞刀 + 单次失效可能巨亏 + 不保证盈利**。
- ⚠️ 点金虚拟盘可试/回测（对比震荡vs趋势），AI 信号仅供参考；信号为参考、非指令、不预测。

## 一、策略原理

均值回归的核心假设是：**价格短期内过度偏离它的"均值"（平均水平）后，有向均值回归的倾向。**（呼应 F14）

背后是一种统计直觉——价格围绕某个中枢上下波动，偏离太远就可能被"拉回来"。所以均值回归策略**做的是"反向"**：价格涨得过高时偏空、跌得过低时偏多，赌它回归均值。这与趋势跟踪（顺势）**正好相反**。

## 二、适用场景与失效场景

- **适用：震荡市、有明确均值中枢的行情。** 价格围绕一个均值上下波动、反复回归时，均值回归策略胜率相对较高。
- ★**失效：趋势市（致命）。** 在单边趋势里，价格会**持续朝一个方向偏离、并不回归**——这时做均值回归就是**逆势"接飞刀"**：你以为"跌多了该反弹"去抄底，结果它继续跌（抄在半山腰）；你以为"涨多了该回落"去做空，结果它继续涨（做空在起飞点）。**均值回归最大的风险，就是遇到单边趋势。**（呼应 C2-5、左侧抄底风险）

## 三、怎么用（信号与规则）

1. **衡量"偏离程度"**：用工具判断价格偏离均值多远——
   - **均线**：价格离均线多远；
   - **布林带**：价格触及上下轨（C3-5 的均值回归用法）；
   - **乖离率（BIAS）**：(价格 − 均线) ÷ 均线 ×100%，直接量化偏离百分比（见 D 词典）。
2. **偏离过大时反向参考**：偏离过高 → 偏空参考；偏离过低 → 偏多参考（**区间/震荡思维**，不是趋势思维）。
3. ★**必须设止损**：万一"不回归"（趋势来了），止损是防止"接飞刀接到重伤"的唯一保护。

**均值回归本质是"区间思维"——它默认价格会回来；一旦价格"不回来"（趋势），就必须靠止损认错离场。**

## 四、优缺点与风险

**优点**：在**震荡市里胜率相对较高**（价格确实常回归）；有统计依据；适合区间行情。

**缺点与风险**：

- ★**趋势里是灾难**：逆势、不回归、可能持续亏损——这是均值回归**最大、最致命的风险**；
- **"接飞刀"风险**：逆势抄底/摸顶，可能在错误方向上越陷越深；
- **单次失效可能很大亏**：均值回归往往"赢的次数多、但输一次输很大"（遇到趋势），**没有止损会被一次趋势重创**；
- **不保证盈利**。
