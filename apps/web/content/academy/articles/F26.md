# 一笔趋势交易的完整复盘（方法演示）

> 点金训练营 · 第五阶 · 模块19 实战案例复盘

**本篇速览**

- 用示意案例完整演示一笔趋势交易：**识别趋势（F8：高低点抬高+均线多头）→ 回调进场（F12，进场前定好理由/止损/仓位）→ 移动止损跟随（让利润奔跑）→ 趋势反转离场（没卖在最高点是正常的）→ 复盘过程对错（F7）**。
- 复盘看的是**过程是否符合规则**（识别/进场/止损/情绪），不是单次盈亏；过程对 + 小亏也可接受。
- ⚠️ 这是**流程/方法演示，不是必然成功的剧本**——真实中可能假突破、进场即止损；趋势跟踪胜率本就不高。
- ⚠️ 红线：**行情为示意/教学、非个股推荐**；进出场为**逻辑示意、非买卖信号**；讲过去不指导现在、不预测、不保证盈利。

## 一、概念引入：把方法走一遍给你看

上一篇（F25）讲了案例复盘的正确姿势：拆当时的结构、可行的应对、过程对错，而不是抄答案。这一篇，我们用一个**示意性**的趋势交易案例，把这套方法**完整地走一遍**——让你看清，一笔顺势交易从识别、进场、持有到离场、复盘，完整流程长什么样。

先把最重要的话放前面：

> ⚠️ 本篇用的是**教学用的、通用化的示意行情**，**不是任何真实个股/品种、不是推荐**。所有的进出场点都是**逻辑示意**、不是买卖信号。它演示的是"流程和方法"，**不是一个"必然成功的剧本"**。

## 二、案例设定（示意）

为了演示，我们设定一个场景（全程示意、不点名品种）：

- 有一段**示意性的上涨趋势行情**；
- 一个交易者使用我们前面学过的**趋势跟踪体系**（F8 的框架 + F12 的具体规则）；
- 我们跟着他，走完识别 → 进场 → 持有 → 离场 → 复盘的全过程。

记住：重点不在"这段行情后来涨了多少"，而在"**每一步的判断和执行，是怎么按方法做出来的**"。

## 三、步骤一：识别趋势（接 F8）

第一步，是判断"当时市场处在什么结构"——用**当时能看到的信息**（不偷看后面）。

交易者观察到的客观结构：

- **高低点结构**：价格的高点在不断抬高、低点也在不断抬高（回顾 A7、F8——这是上涨趋势的典型特征）；
- **均线**：价格运行在向上的均线上方，均线呈多头排列；
- 综合判断：**当前处于一段上涨趋势中。**



![F26 配图1](/academy-img/F26-配图1.png)


注意这一步的纪律：他是**基于已经发生的结构**判断"趋势已经存在"，而**不是预测**"它还能涨多少"。趋势跟踪是跟随，不是预言（回顾 F12）。

## 四、步骤二：回调进场（接 F12）

确认了上涨趋势，接下来是"怎么进"。

按趋势跟踪的规则，交易者**不去追最高点**（那样成本差、风险大），而是**等价格回调**——回调到某条关键均线 / 前期支撑附近、并出现**企稳**迹象时，顺势做多（回调进场，回顾 F12）。

进场的同时，他按"先计划后交易"（F2）把这笔交易的要素**一次性定好**：

- **入场理由**：上涨趋势中、回调到支撑企稳，顺势做多；
- **入场点**：回调企稳的区域；
- **止损位**：跌破本次回调的低点 / 关键均线下方（一旦跌破，说明"回调"可能变成"反转"，判断被证伪）；
- **仓位**：用固定比例风险法（F4），让这一笔即使止损，最多亏总资金的 1%。



![F26 配图2](/academy-img/F26-配图2.png)


这一步的关键：**进场前，亏损的边界（止损）和投入的大小（仓位）就已经确定了**——他清楚"最坏会怎样"。

## 五、步骤三：移动止损跟随（接 F12）

进场后，假设趋势继续向上推进。交易者不预设"涨到某价就必须卖"的硬目标，而是用**移动止损**跟随：

- 随着价格上行，把止损**阶梯式地往上移**（比如跟着不断抬高的低点、或某条均线上移）；
- 这样既**锁住了一部分已有的浮盈**，又**给趋势继续奔跑的空间**（回顾 F12"让利润奔跑"）。

他要做的，是**管住手、按规则持有**——不因为"已经赚了一点"就焦虑地提前跑掉（那是 F5 的恐惧），也不因为"还想赚更多"就把止损撤掉（那是贪婪）。持有阶段的纪律，就是尊重进场时定好的移动止损规则。

## 六、步骤四：趋势反转离场

任何趋势都会结束。假设价格最终涨势衰竭——出现了趋势可能反转的信号：

- 价格**跌破了移动止损**（或者趋势结构转坏：高点不再抬高、跌破关键均线、缠论结构走坏）；
- 按规则，交易者**离场**。

这里有一个**必须接受的事实**：

> 他**没有卖在最高点**。移动止损天然意味着——价格要先从顶部回落一段、触及止损，他才离场，所以**总要让出"从最高点到止损位"的那一段利润**。这不是失误，而是趋势跟踪的**正常代价**（回顾 F12）。想"卖在最高点"是不现实的幻想，按规则在反转后离场，已经是正确的执行。

## 七、步骤五：复盘过程对错（接 F7 四象限）

交易结束，进入最关键的复盘环节。复盘的核心，**不是"这笔赚了多少"，而是"过程做得对不对"**（回顾 F7 对事不对结果）：

- **识别趋势**：当时判断上涨趋势，依据（高低点、均线）充分吗？——过程是否合理。
- **进场**：是按"回调企稳"的规则进的，还是追高冲动进的？——是否符合规则。
- **止损与持有**：止损是否设好并严格执行？移动止损是否按规则跟随？有没有中途因情绪提前跑或撤止损？——执行是否到位。
- **情绪**：全程有没有被恐惧/贪婪干扰？

然后用 F7 四象限定位：如果**过程都符合规则**——那么无论这次是大赚、小赚还是小亏，都属于"**做对了**"那一类（做对 + 赚 = 理想；做对 + 小亏 = 可接受，继续坚持）。复盘要做的，是**确认哪些过程对、哪些可改进**（比如进场时机能不能更好、止损能不能更合理），把方法打磨得更精。

## 八、关键提醒：这是流程演示，不是成功剧本

走完这一遍，必须泼一盆"清醒的冷水"：

- 真实交易里，**这套流程完全可能不成功**——你识别为趋势的，可能是假突破；你回调进场的，可能一进场就跌破止损（判断错、止损出局）。趋势跟踪本就胜率不高、要忍受很多次这样的小亏（回顾 F12）。
- 所以本篇演示的是**"方法和流程"**——即"该怎么一步步按规则做"，**不是"照这么做就一定赚"的剧本**。
- 再次强调：**行情是示意/教学的，不是个股推荐；进出场是逻辑示意，不是买卖信号。**

复盘的价值，正在于：**无论单次输赢，都用同一套流程和"对事不对结果"的标准去打磨过程**——长期靠的是过程的稳定，而不是某一笔的运气。
