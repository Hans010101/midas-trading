# 交易计划：每一笔交易前该想清楚什么

> 点金训练营 · 第五阶 · 模块13 交易体系与实战

**本篇速览**

- **先计划、后交易**：用事前的理性，对抗持仓时的情绪。
- 一份完整交易计划含：**入场理由、入场点、止损位、止盈目标、仓位大小、最坏打算**。
- **计划与执行分离**：执行阶段只照计划做，不在持仓情绪中临时改计划（尤其别乱挪止损）。
- 养成**写交易日志**的习惯，它是执行的监督员、也是复盘的素材。（本篇讲方法，不预测、不承诺收益。）

## 一、概念引入：先计划，后交易

很多亏损的交易，问题不出在"看错"，而出在"没想清楚就下单"——看到价格一动，热血上头就进场，进了之后才开始想"我为什么买、亏了怎么办"。

成熟交易者的做法正好相反：**先有计划，再有交易。** 在下单之前，就把这笔交易的方方面面想清楚、定下来。这一篇讲的就是——一笔交易前，到底该想清楚什么。

## 二、交易计划的意义：把决策提前到"冷静的时候"

交易计划最大的价值，是**把关键决策，从"持仓时情绪翻涌的当下"，提前到"还没下单、头脑冷静的时候"**。

人在持有仓位、面对真金白银的浮动盈亏时，是很难理性的——浮亏时想扛、浮盈时想跑。而如果在进场前就把"什么时候走、亏到哪认输"都定好了，到时候你只需要**执行**，而不是在情绪里临时做决定。这就是计划的意义：**用事前的理性，对抗事中的情绪。**

## 三、一份完整的交易计划，包含什么

一份交易计划，至少应该回答清楚以下几点：

1. **入场理由**：我**为什么**要做这笔交易？依据是什么（趋势、结构、信号）？——如果说不出理由，就不该做。
2. **入场点**：在什么价格 / 什么条件下进场。
3. **止损位**：价格走到哪里，我承认看错、离场？（这是必须项）
4. **止盈目标**：价格走到哪里，我兑现利润？
5. **仓位大小**：这一笔投入多少、最多冒多少风险（见 F4）。
6. **最坏打算**：如果发生极端情况（跳空、滑点），我的预案是什么。

把这几点写下来，一笔交易的"风险有多大、目标在哪、最坏会怎样"就一目了然了。

## 四、有计划 vs 无计划：两种交易的命运

对比一下两种交易者：

- **无计划者**：凭感觉进场 → 不知道在哪止损 → 亏了就扛、心存侥幸 → 小亏拖成大亏；或赚了一点就慌忙跑掉 → 抓不住大行情。决策被情绪牵着走。
- **有计划者**：进场前定好理由、止损、目标、仓位 → 行情来了只需按计划执行 → 亏到止损就走、到目标就兑现 → 情绪的干扰被规则挡在门外。

差别不在于"谁更聪明"，而在于**谁把决定权交给了事先的理性，而不是事中的情绪。**

## 五、计划与执行分离

这里有个重要原则：**计划与执行要分离。**

- **计划阶段**（冷静、没持仓时）：充分分析、把规则定清楚。
- **执行阶段**（持仓、有盈亏时）：只负责"照计划做"，**不在持仓的情绪中临时改计划**。

最常见的错误，就是在持仓时一边扛着浮亏、一边给自己找理由把止损往下挪——这等于在最不该改主意的时候改了主意。**真正的纪律，是在执行阶段尊重计划阶段的自己。**（关于纪律，F6 还会专门讲。）

## 六、写交易日志的习惯

把交易计划和执行过程**记录下来**，形成交易日志，是一个极有价值的习惯：

- 进场前记下计划（理由、止损、目标、仓位）；
- 离场后记下结果，以及"有没有按计划执行、哪里偏离了"。

它既是执行的"监督员"（白纸黑字，赖不掉），也是后续复盘（F7）的原始素材。长期坚持，你会越来越清楚自己的模式和问题。
