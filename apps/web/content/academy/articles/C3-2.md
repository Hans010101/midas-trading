# C3-2 MACD 策略：金叉死叉、柱状图与背离

> 点金训练营 · C3 策略专题库

MACD 是最流行的动能指标之一，围绕它的策略也很多。这一篇讲清 MACD 策略的原理、用法和边界——并把那个**最常被搞错的定义**钉死。

**本篇速览**

- MACD = **DIF（快均线−慢均线）+ DEA（DIF 的均线）+ 红绿柱（DIF−DEA）**，反映动能。
- ★**MACD 金叉 = DIF 上穿 DEA（柱由绿翻红）、死叉 = DIF 下穿 DEA**——主角是 DIF/DEA，**不是均线**（别和均线金叉混）。
- 用法：金叉死叉作偏多偏空参考、红绿柱看动能强弱、**背离提示动能衰竭（非精确择时、会钝化/失败）**。
- 缺点：**滞后 + 震荡假信号 + 背离不精确 + 不保证盈利**。
- ⚠️ 点金虚拟盘可试/回测，AI 信号仅供参考；信号为参考、非指令、不预测。

## 一、策略原理

MACD 由三部分构成（见 B4）：

- **DIF（快线）= 快均线 − 慢均线**（常用 12、26）；
- **DEA（慢线）= DIF 的移动平均**（常用 9），更平滑、滞后于 DIF；
- **红绿柱 = DIF − DEA**（DIF 在上为正/红、在下为负/绿，相交为零）。

MACD 反映的是**趋势的"动能"**——价格上涨/下跌背后的力量强弱。MACD 策略，就是用它来判断**动能的方向与强弱**，辅助决策。

## 二、适用场景与失效场景

- **适用：有一定趋势 / 动能的行情。** 价格有方向、有力度时，MACD 的金叉死叉和柱状图能较好地反映动能变化。
- **失效：震荡行情。** 震荡里 MACD 同样会**频繁金叉死叉、给出假信号**；背离也容易**钝化、失败**。

## 三、怎么用（信号与规则）

**1. 金叉 / 死叉（★定义务必记准）：**

- **MACD 金叉 = DIF 上穿 DEA**（柱由绿翻红），偏多参考；
- **MACD 死叉 = DIF 下穿 DEA**（柱由红翻绿），偏空参考。

⚠️ **注意：MACD 金叉的主角是 DIF、DEA 两条线，不是均线！** "短期均线上穿长期均线"那是**均线金叉**（C3-1），两者别混——这是最常见的硬伤。

**2. 红绿柱看动能强弱：**
柱**变长 = 动能增强**、柱**缩短 = 动能减弱**；红柱见顶回缩，常意味上涨劲头在衰竭。

**3. 背离看动能衰竭（见 B6）：**
- **顶背离**：价格创新高，但 MACD 高点**反而降低** → 上涨动能衰竭；
- **底背离**：价格创新低，但 MACD 低点**反而抬高** → 下跌动能衰竭。
- 背离提示"**可能反转**"，但**不是精确择时**（会钝化、可能失败）。

## 四、优缺点与风险

**优点**：兼顾**趋势方向和动能强弱**；背离能提前提示动能衰竭；比单纯看价格多一个维度。

**缺点与风险**：

- **滞后**：MACD 由均线衍生，本质是滞后指标，信号出现时价格常已走一段；
- **震荡假信号多**：和均线策略一样的痛点；
- **背离不精确**：背离可能**钝化**（强趋势里看着背离却继续走）、可能**失败**，不能当"反转保证"（呼应 C1-18）；
- **不保证盈利**。
