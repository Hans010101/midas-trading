# 一笔失败交易的复盘：从亏损里学什么

> 点金训练营 · 第五阶 · 模块19 实战案例复盘

**本篇速览**

- 用示意案例演示一笔失败交易（**逆势抄底接飞刀 + 不止损扛单 → 大亏/爆仓**），属于 F7 四象限"做错 + 亏钱 = 必须改"。
- 拆解：**判断错（方法层面：不该逆势抄底 → 改方法）** + **执行错（纪律层面：不该不止损扛单 → 改纪律）**，本案两者都错；分清两类问题才能对症。
- **情绪（F5）是根子**：抄底的侥幸/贪婪、扛单的"希望"——对抗它靠事前规则与纪律。
- ★**对事不对结果**：即使侥幸赚了也是"做错+赚钱"的危险格（靠运气、强化坏习惯）；**失败案例只讲教训、不羞辱**。
- ⚠️ 红线：行情为**示意/教学、非个股推荐**；进出场为**逻辑示意、非买卖信号**；讲过去不指导现在、不预测、不保证盈利。

## 一、概念引入：亏损，才是最好的老师

上一篇演示了一笔顺利的趋势交易。但真实交易里，**亏损是常态**——再成熟的交易者也会亏。所以，比起"赚钱的案例"，**从"失败的案例"里学，往往收获更大**。

这一篇，我们用一个**示意性**的失败案例，演示怎么从一笔亏损交易里**学到真东西**——而不是陷入懊恼、自责，或者干脆把它忘掉。

先把红线立在前面：

> ⚠️ 本篇用的是**教学用的、通用化的示意案例**，**不点名任何真实个股/品种**。复盘失败案例，目的是**冷静地拆解"哪里做错了、怎么改"，只讲教训、绝不羞辱**（无论是别人还是自己）。行情为示意、进出场为逻辑示意、非买卖信号。

## 二、案例设定（示意）

设定一个新手很容易踩坑的场景（全程示意、不点名）：

- 有一段**示意性的下跌行情**（高点、低点不断降低——典型的下跌趋势）；
- 一个交易者犯了两个**最常见的致命错误**：**逆势抄底"接飞刀"** + **不止损扛单**；
- 我们来还原这个过程，并用学过的方法拆解它。

## 三、错误发生的过程（还原"当时"）

我们站在"当时"的视角，还原这笔交易是怎么一步步走向大亏的：

**第一步：逆势抄底（接飞刀）。**
价格已经持续下跌一段时间，处在明确的**下跌趋势**里。交易者心想："跌这么多了，应该差不多到底了吧？"——于是，在**没有任何企稳/反转信号**的情况下，**逆着下跌趋势买入抄底**（这就是 F16 讲的"左侧抄底"中最危险的一种——**接飞刀**）。

**第二步：不止损、扛单。**
买入后，价格**没有如他所愿反弹，而是继续下跌**。这时正确的做法是按计划止损离场。但他**没有设止损**（或设了却不执行），而是抱着"它总会涨回来的"的念头**死扛**（这正是 F5 讲的"**希望**"情绪陷阱）。

**第三步：亏损扩大。**
价格继续下行，浮亏越来越大。扛到最后，要么割肉认了一笔大亏，要么（如果是合约且用了杠杆）直接**爆仓**出局（回顾 E4：浮亏接近保证金即被强平）。

一笔本可以"小亏离场"的交易，因为这两个错误，变成了"大亏 / 爆仓"。

## 四、用 F7 四象限定位：这是"做错 + 亏钱"

先用 F7 的四象限给这笔交易定个位：它的**过程是错的**（逆势抄底 + 不止损都违背了方法和纪律），**结果也是亏的**——落在"**做错 + 亏钱**"那一格，也就是 F7 说的"**必须改**"的那一类。

定位清楚了，接下来才是复盘的核心：**到底错在哪？是判断错，还是执行错？**

## 五、拆解：判断错，还是执行错？（接 F7）

F7 讲过，复盘要分清"判断错（方法问题）"和"执行错（纪律问题）"——因为它们的**改进方向完全不同**。这笔失败交易，**两类错误都犯了**：

**判断错（方法层面）：不该逆势抄底。**
在一个明确的**下跌趋势**里，没有任何企稳信号就去抄底，本身就**违背了"顺势 / 等确认"的原则**（回顾 F8 顺势、F16 左侧抄底的极高风险）。这是**方法层面**的错——他选择了一个胜算很低、风险极高的打法（接飞刀）。**改进方向：改方法**——别在下跌趋势里逆势接刀，要么顺势、要么等真正的企稳/反转确认（右侧）。

**执行错（纪律层面）：不该不止损、扛单。**
退一步说，**即使进场判断错了**，如果他**设了止损并严格执行**，这笔最多也就是亏 1%（回顾 F4），绝不至于演变成大亏 / 爆仓。但他**没止损、还扛单**——这是**纪律层面**的错。**改进方向：改纪律**——必须设止损、必须执行，绝不扛单。



![F27 配图2](/academy-img/F27-配图2.png)


**这笔交易"判断 + 执行"双错**：方法上不该接飞刀，纪律上不该扛单。复盘的价值，正在于把这两类问题**分开看清、分别对症**——而不是笼统地说一句"我太菜了"。

## 六、情绪如何起作用（接 F5）

再往深一层，看情绪（F5）在背后扮演了什么角色——因为很多"判断错 / 执行错"，根子在情绪：

- **"跌这么多该反弹了"**：这是一种**抄底的侥幸 / 贪婪**——想抄在最低点、占便宜，于是忽视了下跌趋势的客观事实。
- **扛单不止损**：这是**"希望"**情绪（F5）在作祟——亏损时一厢情愿地期待回本，不愿面对"我错了"。
- 整个过程，是**情绪压过了规则**：如果当时按事先的规则（顺势、止损）机械执行，这两个错误本都可以避免。

这印证了 F5、F6 的核心：**对抗情绪，靠的是事前的规则和纪律，而不是事中的"我觉得"。**

## 七、★关键：对事不对结果，失败只讲教训

复盘失败案例，有两个最重要的态度（都接 F7）：

**1. 对事不对结果——即使侥幸赚了，也是"危险"。**
假设换一种情况：他这次接飞刀 + 扛单，结果**运气好、价格真反弹了，赚了一笔**。这能说明他做对了吗？**绝对不能。** 这属于 F7 四象限里"**做错 + 赚钱**"那一格——**最危险的一格**：靠运气赚到的钱，会让他**误以为"接飞刀 + 扛单"是有效的**，从而不断重复这个坏习惯，**早晚有一次会被市场连本带利收回去**。所以，评价的永远是**过程**，不是单次结果。

**2. 失败案例只讲教训，不羞辱。**
复盘失败，不是为了懊恼"我当时怎么这么蠢"、更不是为了否定自己。它的唯一目的，是**冷静地拆出"哪里错了、下次怎么改"**，把这次的亏损**变成一笔有价值的"学费"**。**羞辱自己**只会带来情绪内耗、甚至引发报复性交易（F5），对改进毫无帮助。对别人的失败案例同理——我们分析教训，不嘲笑当事人。

## 八、在点金虚拟环境里"先犯错"

这种昂贵的教训，最好的学习方式是**在零真实风险的环境里亲历一次**：

- 在点金的**全程虚拟**环境里，可以零成本地体验一次"**逆势抄底 + 扛单**"的失败过程（甚至看到合约里如何一步步爆仓），把这个教训**用虚拟资金交了学费**；
- 然后用本篇的方法（判断错 vs 执行错、情绪分析、四象限），对自己的虚拟交易做复盘练习。

> ⚠️ 点金全程虚拟，所有分析与 AI 功能**仅供参考、不构成投资建议、不预测**；虚拟成绩不代表真实结果。它帮你把错误零成本地犯在虚拟里、并学会复盘，绝不是鼓励你去冒险。
