# C1-15 用缠论完整推演一段下跌行情（示意）

> 点金训练营 · 缠论进阶 · 完整复盘篇

上一篇推演了上涨行情。这一篇推演**下跌行情**——流程完全一样，只是方向相反、买点换成卖点。把它和 C1-14 对照着看，你会更牢地掌握缠论"上下对称"的结构逻辑。

> ⚠️ 同样：**教学用的虚构 / 示意下跌行情，不点名真实标的、不做"该卖该买"的判断**。卖点标注为**结构位置**、非买卖指令；涉及做空更要注意风险。

## 一、第一步：K 线包含 → 分型 → 连笔

和上涨一样从地基做起：

1. **K 线包含处理**（下跌方向同样按规则做非包含合并）；
2. **找分型**（顶分型、底分型）；
3. **连笔**（分型间至少 3 根 K 线、不共用）。

下跌行情里，你会看到笔在**整体向下**的背景里上下交替。

![C1-15 配图1](/academy-img/C1-15-配图1.png)

## 二、第二步：笔 → 线段

把笔连成线段（至少三笔、有重叠），用**特征序列**判断线段结束。注意：**向下线段的特征序列，取向上笔**（与线段方向相反，见 C1-1）——方向别搞反。

## 三、第三步：找中枢

找至少三段次级别走势的重叠区，画中枢，取值**不变**：

- **中枢上沿 ZG = 三段高点的最小值**；
- **中枢下沿 ZD = 三段低点的最大值**。

（取值和方向无关，下跌行情里 ZG/ZD 的算法和上涨完全一样。）

![C1-15 配图2](/academy-img/C1-15-配图2.png)

## 四、第四步：判断走势类型

数中枢、看方向：

- 只有**一个中枢** → 盘整；
- **两个或以上、依次降低**的中枢 → **下跌趋势**（中枢一级级往下接力）。

## 五、第五步：标出卖点（结构位置，镜像买点）

下跌行情里标的是**卖点**，和买点完全镜像（**全程结构位置、非买卖指令**）：

- **1 卖**：这段下跌**之前**的那段上涨趋势末端、出现**趋势背驰**后的转折处；
- **2 卖**：1 卖之后，价格反抽再下行、**反抽不破前高**的那个点；
- **3 卖**：中枢被**向下跌破**后，价格反抽**不回中枢（不破 ZD）**的那个点。

注意 3 卖的条件是"**不破 ZD（中枢下沿）**"——和 3 买"不破 ZG"镜像，别记混。

![C1-15 配图3](/academy-img/C1-15-配图3.png)

## 六、第六步：用背驰看下跌的"健康度"

用 **MACD** 看下跌**末端有没有趋势背驰**——下跌看**绿柱面积**：

- 价格创新低，但**绿柱面积明显缩小** + 黄白线回拉 → **底背驰**，下跌力度衰竭，这段下跌可能要完成；
- 同样（接 C1-18）：**底背驰 ≠ 立刻见底反弹**——之后可能反转、可能转盘整、也可能继续创新低（钝化）。别把底背驰当"抄底保证"。

## 七、复盘小结（含做空风险提示）

下跌行情的推演，和上涨**完全对称**：流程一样、取值一样、卖点是买点的镜像。这正体现了缠论结构的"上下对称之美"。

但有一句必须补充：

> ⚠️ 如果在**合约**里据此做空，请记住做空 / 杠杆的风险——**放大收益必然同等放大亏损、可能爆仓**；且本篇只是**结构分析的示意演示**，**不构成做空建议、不预测会不会继续跌**。底背驰也可能钝化、下跌继续。

## 八、本篇要点

- 下跌行情推演与上涨**完全镜像**：**K 线包含 → 分型 → 笔 → 线段（向下线段特征序列取向上笔）→ 中枢（ZG/ZD 取值不变）→ 走势类型（≥2 个依次降低中枢 = 下跌趋势）→ 卖点 → 末端背驰**。
- 卖点镜像买点：**1 卖 = 上涨趋势背驰转折、2 卖 = 反抽不破前高、3 卖 = 跌破中枢反抽不回中枢（不破 ZD）**。
- 末端**底背驰**（绿柱面积缩小 + 黄白线回拉）提示下跌可能完成，但**底背驰 ≠ 立刻见底反弹**（会钝化、有三种演化）。
- ⚠️ **示意 / 虚构行情、非真实标的、非买卖建议、不预测**；做空 / 杠杆有放大亏损与爆仓风险。
