# 做多与做空：双向都能赚钱

> 点金训练营 · 第一阶 · 模块4 交易的基础概念

**本篇速览**

- 市场可以**双向获利**：做多押涨，做空押跌。
- **做多**：先买后卖，价格涨了赚、跌了亏。
- **做空**：先卖后买（"借入卖出、跌了买回"的类比），价格跌了赚、涨了亏；合约里通过"开空头仓位"实现，无需真的借实物。
- **现货**因为要先持有/借入，通常以做多为主；**合约**从设计上支持双向，做多做空都方便。
- 做多与做空**盈亏方向相反**；任何方向都要为"看错"做准备（风险管理）。

## 一、概念引入：赚钱不只有"等它涨"这一条路

很多新手对交易的第一印象是："买入，然后等它涨，涨了卖掉赚钱。"这没错，但这只是一半。

在市场里，价格有涨有跌。如果只能在"涨"里赚钱，那一半的行情（下跌）就只能干看着。于是市场设计了两种方向相反的玩法：

- **做多**：押注价格会**涨**。
- **做空**：押注价格会**跌**。

两者方向相反，但都能盈利——区别只在于你判断的方向，以及价格实际怎么走。**注意：这里讲的是"两种工具/方向各自怎么运作"，不是教你预测涨跌，更不是说哪个方向一定赚。**

## 二、做多：低买高卖，最好理解的方向

**做多**就是最符合直觉的那种交易：**在你认为价格低的时候买入，在价格涨上去之后卖出，赚取中间的差价。**

- 价格如你所料上涨 → 卖出价高于买入价 → **盈利**。
- 价格不如预期下跌 → 卖出价低于买入价 → **亏损**。

一句话：**做多是"先买后卖"，价格涨了才赚。**

## 三、做空：先卖后买，跌了反而赚

**做空**是新手最容易绕晕的概念，我们用一个生活化的类比讲清楚。

假设你**借**了朋友一台相机（你手里并没有这台相机的所有权，只是借来的），此刻市价 1 万元。你判断它会降价，于是马上把它按 1 万元卖掉，拿到 1 万元现金。过了一阵，这款相机果然降到了 8 千元，你花 8 千元买回一台**一模一样的**还给朋友。一借一还，相机物归原主，而你手里**净赚了 2 千元**的差价。

做空的逻辑就是这样：**先在高价时（借入并）卖出，等价格跌下来再低价买回，赚下跌的差价。**

- 价格如你所料下跌 → 买回价低于卖出价 → **盈利**。
- 价格不如预期上涨 → 买回价高于卖出价 → **亏损**。

一句话：**做空是"先卖后买"，价格跌了才赚。**

（说明：在合约交易里，你并不需要真的去"借"一个币或一只股票。你只要"开一个空头仓位"，系统就会让你的盈亏按"跌了赚、涨了亏"来计算——"借入卖出"是帮助你理解做空原理的类比。）

## 四、为什么合约能做空，现货一般只能做多

这要从"你手里到底有没有东西"说起。

**现货交易**：你用钱**买入并真正持有**那个资产（比如买入并持有某只股票、某个币）。你拥有它，自然可以在涨价后卖出获利。但如果你想做空——在不持有的情况下"先卖"——你得先**借到**这个资产才能卖，而这种借券/借币的渠道对普通散户往往不开放或较复杂。所以**现货通常以做多为主**。

**合约交易**（如永续合约、期货）：合约本质是一份"价格变动的协议"，它**从设计上就支持双向**。你可以开"多头"合约（价格涨了赚），也可以开"空头"合约（价格跌了赚），不需要真的去借实物。所以**合约能方便地做多，也能方便地做空**。

## 五、做多与做空：盈亏方向正好相反

把两者放一起对比，记住一组对称关系：

| | 做多 | 做空 |
|---|---|---|
| 看法 | 看涨 | 看跌 |
| 操作顺序 | 先买后卖 | 先卖后买 |
| 价格上涨时 | 盈利 | 亏损 |
| 价格下跌时 | 亏损 | 盈利 |

它们就像一枚硬币的两面：**同一段行情，做多的人和做空的人，盈亏正好相反。**

也正因如此，无论你用哪个方向，都必须对"判断错了怎么办"有所准备——这就引出了后面要讲的风险管理（止损等）。做空尤其要注意：理论上价格上涨没有上限，所以**做空在方向看错时的潜在亏损可能很大**，这一点在后面合约和风险管理的内容里会专门讲。

## 六、本篇要点

- 市场可以**双向获利**：做多押涨，做空押跌。

- **做空**：先卖后买（"借入卖出、跌了买回"的类比），价格跌了赚、涨了亏；合约里通过"开空头仓位"实现，无需真的借实物。
- **现货**因为要先持有/借入，通常以做多为主；**合约**从设计上支持双向，做多做空都方便。
- 做多与做空**盈亏方向相反**；任何方向都要为"看错"做准备（风险管理）。
