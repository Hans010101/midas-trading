# C3-6 RSI 策略：超买超卖与背离，震荡市的用法与趋势市的失效

> 点金训练营 · C3 策略专题库

RSI 是最常见的"超买超卖"指标。但很多人用它栽了大跟头——因为他们不知道 **RSI 在趋势市里会"失效"**。这一篇讲清 RSI 策略的用法和那个致命边界。

**本篇速览**

- RSI：**0–100、50 中轴**，>70 超买/<30 超卖（参考、阈值非唯一）；**超买≠马上跌、超卖≠马上涨**。
- **适用震荡市、失效于趋势市**：★强趋势里 RSI **钝化**（长期停极值区），"超买做空/超卖做多"会被反复打脸。
- 用法：超买超卖**仅震荡市作参考 + 配止损**；**背离**提示动能衰竭（非精确择时、会钝化/失败）。
- 缺点：**趋势里失效 + 超买超卖非反转信号 + 背离不精确 + 不保证盈利**。
- ⚠️ 点金虚拟盘可试/回测（对比震荡vs趋势），AI 信号仅供参考；信号为参考、非指令、不预测。

## 一、策略原理

RSI（相对强弱指数）是一个 **0–100** 的数值，反映近期**涨跌力量的对比**（见 B9）：

- **50 为中轴**：上方表示涨势力量占优、下方表示跌势力量占优；
- **超买区常以 >70、超卖区常以 <30** 为参考（阈值非唯一）。

RSI 策略，就是用"RSI 处在什么区域、有没有背离"来辅助判断。但请先记住最关键的一句（红线）：**超买不等于马上跌、超卖不等于马上涨——它是参考区域，不是反转信号。**

## 二、适用场景与失效场景

- **适用：震荡市。** 价格在区间里来回时，RSI 到超买区往往偏高、到超卖区往往偏低，对"区间内的回归"有一定参考意义。
- ★**失效：趋势市（最大坑）。** 在**强趋势**里，RSI 会**钝化**——**长时间停留在超买区（强涨）或超卖区（强跌）而价格继续单边走**。这时如果你"一看超买就做空、一看超卖就做多"，会被趋势**反复打脸、甚至重创**。

**RSI 是"震荡市的参考、趋势市的陷阱"——用之前必须先分清环境。**

## 三、怎么用（信号与规则）

1. **超买 / 超卖（仅震荡市作参考）**：
   - RSI 进入**超买区（>70）** → 涨势力量占优的参考（**震荡里**可能偏高、回落）；
   - RSI 进入**超卖区（<30）** → 跌势力量占优的参考（**震荡里**可能偏低、回升）；
   - ⚠️ 必须配合"现在是不是震荡"来用，且配合止损。
2. **背离（见 B9、原理同 MACD 背离）**：
   - **顶背离**：价格创新高，RSI 高点反而降低 → 上涨动能衰竭参考；
   - **底背离**：价格创新低，RSI 低点反而抬高 → 下跌动能衰竭参考；
   - 背离提示"可能反转"，但**不是精确择时**（会钝化、可能失败）。

## 四、优缺点与风险

**优点**：**直观**（一个数看强弱）；**震荡里有参考价值**；背离能提示动能衰竭。

**缺点与风险**：

- ★**趋势里失效（钝化）是最大坑**：强趋势中 RSI 长期停在极值区，"超买做空/超卖做多"会被趋势反复收割；
- **超买超卖 ≠ 反转信号**：最常见的误用；
- **背离不精确**：会钝化、可能失败；
- **不保证盈利**。
