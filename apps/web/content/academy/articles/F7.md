# 复盘：从每一笔交易中学习

> 点金训练营 · 第五阶 · 模块13 交易体系与实战

**本篇速览**

- **复盘是进步的核心引擎**：把每笔交易变成学习样本，避免重复犯错。
- 复盘要分清**判断错（改方法）还是执行错（改纪律）**，并审视**情绪的影响**。
- **对事不对结果**（重点）：看过程对错而非单次盈亏——最危险的是"做错却赚钱"（靠运气、强化坏习惯），"做对却亏钱"可接受（概率波动，继续坚持）。
- 复盘是**记录 → 回顾 → 总结 → 改进**的循环。（本篇强调学习迭代，不预测、不承诺。）

## 一、概念引入：进步，来自回头看

为什么有人交易很多年还在原地踏步，有人却越做越成熟？差别常常在于一件事：**有没有认真复盘。**

不复盘的交易，每一笔都是孤立的、做完就忘的，错误会一次次重复；而复盘，把每一笔交易变成"学习的样本"，让你从经验里真正长出能力。**复盘，是交易者进步的核心引擎。** 这一篇讲怎么复盘、以及复盘中最重要的一个原则。

## 二、复盘要复什么

复盘不是简单看"这笔赚了还是亏了"，而是要深入问几个问题：

- **对错的原因**：这笔交易做得好不好？好在哪、问题出在哪？
- **是判断错，还是执行错？** 这是关键的一分——
  - **判断错**：分析、规则本身有问题（比如对趋势看反了）。
  - **执行错**：规则没错，但你没照做（比如没按计划止损、提前跑了、乱加仓）。
  - 两者的改进方向完全不同：判断错要改方法，执行错要改纪律。
- **情绪如何影响了这笔交易**：有没有被恐惧、贪婪、侥幸带跑？

把这些想清楚，复盘才有价值——你才知道下一次该改什么。

## 三、最重要的原则：对事不对结果

这是复盘里**最重要、也最反直觉**的一点：**评价一笔交易，要看"过程对不对"，而不是只看"这次赚没赚"。**

为什么？因为单笔交易的结果，**含有大量运气成分**——过程正确也可能因为概率而亏，过程错误也可能因为运气而赚。如果只用"赚 / 亏"来评判，你会得出完全错误的结论。

把"过程对错"和"盈亏结果"组合起来，有四种情况（这就是著名的"四象限"）：

| | 赚钱 | 亏钱 |
|---|---|---|
| **过程做对** | ✅ 理想：又对又赚 | 🟡 可接受：过程对，亏是概率，继续坚持 |
| **过程做错** | ⚠️ 危险：靠运气赚的，会强化坏习惯 | ❌ 必须改：过程和结果都错 |

最需要警惕的，是**"做错了却赚钱"那一格**——它最危险，因为运气会让你误以为错误的做法有效，从而不断重复，迟早被市场收回去。而**"做对了却亏钱"那一格**，反而是可以接受的：只要过程符合体系，单次亏损只是概率的正常波动，应该继续坚持。

**结论：过程正确，比单次结果更重要。** 复盘的目标，是不断打磨"过程"，而不是为单次的输赢患得患失。

## 四、怎么复盘：一个循环

复盘是一个可以固定下来的循环流程：

1. **记录**：交易时就记下计划与执行（接上 F2 的交易日志）。
2. **回顾**：事后回看——当时怎么想、怎么做、结果如何。
3. **总结**：判断过程对错、是判断问题还是执行问题、情绪起了什么作用。
4. **改进**：把结论变成对规则或纪律的具体调整。
5. → 带着改进进入下一笔，再记录、再回顾……如此循环。



![F7 配图3](/academy-img/F7-配图3.png)


这个"记录 → 回顾 → 总结 → 改进"的循环不断转动，你的体系和执行力就在一轮轮迭代中变强。
